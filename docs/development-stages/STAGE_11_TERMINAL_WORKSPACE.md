# 阶段 11：终端工作区效率

## 1. 阶段目标

在现有多标签终端上增加横向/纵向分屏、布局保存、标签管理和可配置自动重连，使用户能够同时观察多个会话，并在应用重启后安全恢复工作区入口而不恢复远端进程或未发送输入。

## 2. 前置条件

- 阶段 8 连接所有权和复用模型稳定。
- 当前多标签、PTY resize、搜索、剪贴板和手动重连回归通过。
- 恢复前端设计规范并确认分屏、标签和工作区视觉方案。
- 定义 Workspace schema、降级策略和快捷键冲突规则。
- 完成多 xterm 实例的内存和渲染性能技术验证。

## 3. 范围与非范围

本阶段包含：

- 横向和纵向分屏；
- 窗格树、拖拽尺寸和基础布局模板；
- 标签拖拽排序、复制连接入口和最近关闭恢复；
- 重启后恢复标签入口和布局；
- 可配置自动重连、最大次数和退避；
- 快捷键集中管理与冲突检测；
- 多窗格状态隔离和性能优化。

本阶段不包含：

- 跨窗口拖拽和多主窗口；
- 远端进程、Shell 状态或终端缓冲持久化；
- 会话录制回放；
- 广播输入和并发命令，放到阶段 12；
- 本地终端。

## 4. 工作区模型

### 4.1 布局树

```ts
type PaneNode =
  | { type: 'leaf'; id: string; sessionRef?: RestorableSessionRef }
  | { type: 'split'; id: string; direction: 'horizontal' | 'vertical'; ratio: number; children: [PaneNode, PaneNode] }

interface WorkspaceTab {
  id: string
  title: string
  root: PaneNode
  activePaneId: string
}
```

- `ratio` 限制在安全范围，避免零尺寸窗格。
- 运行期 SessionState 与可持久化 RestorableSessionRef 分离。
- 快速连接和临时凭据会话默认不可持久化连接引用。
- schema 无法解析时回退为空工作区并保留损坏数据诊断副本。

### 4.2 可恢复会话引用

仅允许保存：

- 已保存 ConnectionProfile ID；
- 标签标题覆盖值；
- 是否自动重连的非敏感策略；
- 窗格位置和大小。

禁止保存：

- 密码、验证码、私钥口令和临时代理凭据；
- 终端缓冲、选择内容和未发送输入；
- 远端 PID、前台进程或“可恢复远端状态”的误导标志。

## 5. 详细开发功能

### 5.1 分屏操作

- 当前窗格支持向右和向下拆分。
- 新窗格可连接新服务器或选择已有保存连接。
- 拖拽分隔条调整比例，变化后节流发送各自 PTY resize。
- 关闭窗格时只关闭其会话；最后一个窗格关闭后关闭标签。
- 分屏失败不改变原布局。
- 提供常用 1、2、4 窗格布局模板，不引入任意复杂模板编辑器。

### 5.2 焦点与快捷键

- 始终有且仅有一个活动窗格。
- 点击、键盘切换和搜索关闭后正确恢复终端焦点。
- 支持在窗格间按方向切换。
- `Ctrl+W` 关闭活动窗格或单窗格标签，行为需清晰一致。
- 快捷键注册集中化，检测浏览器、xterm 和应用全局冲突。
- IME 组合期间不拦截普通输入快捷键。

### 5.3 标签增强

- 标签可拖拽排序，顺序即时保存。
- 提供“使用同一连接新建标签”，建立新 Shell 而非克隆会话。
- 保留有限最近关闭列表，只记录可恢复连接引用。
- 恢复关闭标签前重新执行主机密钥和认证流程。
- 活动标签关闭后选择相邻标签，规则稳定可测试。

### 5.4 工作区持久化与恢复

- 布局变更使用防抖和原子写入。
- 应用启动先渲染安全占位，再按用户设置决定是否连接。
- 默认恢复布局和连接入口，不自动发起需要临时秘密的会话。
- 已保存凭据且用户开启自动连接时也必须遵守主机密钥和风险提示。
- 缺失连接引用在原窗格展示可修复状态，可选择替换或关闭。
- 旧 schema 迁移和损坏 schema 降级不阻止主窗口启动。

### 5.5 自动重连

- 默认关闭，由用户对全局或连接明确启用。
- 仅对网络中断、远端意外关闭等可重试错误生效。
- 用户主动关闭、认证拒绝、主机密钥变化和配置错误不得自动重连。
- 使用指数退避、最大次数和倒计时；用户可立即重试或取消。
- keyboard-interactive、每次询问和临时秘密必须重新询问。
- 重连建立新 Shell，并在原终端缓冲插入明显分隔线。

### 5.6 性能与资源

- 隐藏标签保持缓冲但降低非必要 React 更新。
- 可见窗格分别批量接收输出，不能共享 xterm 实例。
- ResizeObserver 按窗格节流，避免拖拽期间 IPC 风暴。
- 限制单工作区最大窗格数，超过时提示新建标签。
- 单窗格失败不卸载其他窗格。

### 5.7 错误码

至少覆盖：

```text
WORKSPACE-SCHEMA-INVALID
WORKSPACE-RESTORE-FAILED
WORKSPACE-CONNECTION-MISSING
PANE-LIMIT-REACHED
RECONNECT-NOT-ALLOWED
RECONNECT-LIMIT-REACHED
```

## 6. 测试与验证

- 布局树 split、close、resize、排序和序列化属性测试。
- 1、2、4、10 窗格状态和输出隔离。
- 标签拖拽、最近关闭、缺失连接和损坏 schema。
- 应用正常退出、强制退出和写入中断后的恢复。
- 临时密码、验证码、缓冲和未发送输入不进入工作区文件。
- `vim`、`top`、`less`、`tmux`、中文 IME 和终端搜索焦点。
- 网络抖动、服务器关闭、认证过期、主机密钥变化和用户关闭下的自动重连。
- 持续 5 MiB 输出和拖拽 resize 时 UI 响应、IPC 数量和内存趋势。

## 7. 任务拆分

1. 多 xterm 性能验证和 Workspace 模型评审。
2. 布局树 reducer、序列化、迁移和属性测试。
3. 分屏容器、焦点和 PTY resize。
4. 标签排序、复制入口和最近关闭。
5. 原子持久化、启动恢复和安全降级。
6. 自动重连策略、错误分类和倒计时 UI。
7. 快捷键集中化、IME 和无障碍验收。
8. 多窗格压力、恢复和秘密扫描。

## 8. 阶段交付物

- Workspace 模型和恢复架构说明。
- 分屏、标签增强和布局持久化功能。
- 自动重连策略和错误分类表。
- 多窗格性能、异常恢复和安全测试记录。
- 快捷键、工作区和已知限制用户文档。

## 9. 退出条件

- 多层分屏的输入、输出、搜索和 resize 不串线。
- 工作区重启恢复不保存秘密、不自动执行输入。
- schema 损坏和连接缺失不会阻止应用启动。
- 自动重连只处理允许的错误并受次数/退避限制。
- 10 会话压力测试和常见全屏程序验收通过。
- 关闭窗格、标签和应用后无 SSH 会话或任务残留。
