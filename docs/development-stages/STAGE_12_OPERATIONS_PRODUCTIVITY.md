# 阶段 12：运维生产力

## 1. 阶段目标

在安全、隔离的终端工作区基础上，增加快速命令、并发会话、显式广播、批量文件分发、服务器监控和小型远程文本编辑，覆盖 XTerminal 的本地 SSH 核心运维工作流。

## 2. 前置条件

- 阶段 9 的批量 SFTP 和 TransferRegistry 稳定。
- 阶段 11 的窗格、焦点、快捷键和恢复模型稳定。
- 快速命令模板语法、广播安全交互和监控采集协议完成评审。
- 明确远程编辑的文件大小、编码、冲突检测和原子保存边界。
- 准备 20 个 loopback 会话和 Linux 监控测试环境。

## 3. 范围与非范围

本阶段包含：

- 本地快速命令仓库、单层分组、搜索和参数变量；
- 预览、复制、粘贴到终端和明确立即执行；
- 并发会话、显式广播输入和结果汇总；
- 向多个会话批量分发文件；
- CPU、内存、负载、磁盘、网络和运行时间监控；
- 小型 UTF-8 远程文本文件编辑和保存冲突检测。

本阶段不包含：

- 云端命令仓库、团队共享和审批流；
- 任意脚本编排语言、定时任务和无人值守执行；
- AI 命令生成；
- 完整 IDE、语言服务器和大型二进制文件编辑；
- 监控告警平台、历史时序数据库和遥测上传。

## 4. 快速命令

### 4.1 数据模型

```ts
interface QuickCommand {
  id: string
  groupId: string
  name: string
  command: string
  description?: string
  parameters: Array<{
    key: string
    label: string
    required: boolean
    secret: boolean
    defaultValue?: string
  }>
  updatedAt: string
}
```

- 命令和非秘密默认值保存在本地版本化资产中。
- secret 参数值只在本次执行内存存在，不进入历史。
- 参数占位符使用简单、可审计语法，不支持表达式求值或本地命令替换。
- 导出快速命令时排除参数历史和秘密。

### 4.2 功能

- 新建、编辑、复制、删除、分组和搜索。
- 填写参数后展示最终命令预览。
- “复制”“粘贴但不执行”“立即执行”三个动作明确分离。
- 多行或超过安全阈值的命令继续触发安全粘贴确认。
- 参数历史按命令和参数键保存有限条目，秘密参数不保存。
- 删除和立即执行具备清晰焦点与键盘行为。

## 5. 并发会话与广播

### 5.1 会话集合

- 用户显式选择多个已保存连接组成临时并发会话。
- 每个目标拥有独立连接、终端、状态和错误。
- 一个目标失败不取消其他目标，除非用户选择“全部停止”。
- 汇总连接中、成功、失败和已取消数量。

### 5.2 广播模式

- 默认关闭，开启后在所有目标窗格持续显示高可见状态。
- 输入框明确列出目标数量和连接名称。
- 支持发送到选中目标，不把断开会话计为成功。
- Ctrl+C 等控制序列发送前展示目标范围，不修改其字节语义。
- Escape 或明显按钮可立即退出广播。
- 广播内容不进入诊断日志。

### 5.3 批量文件分发

- 复用阶段 9 TransferRegistry 向多个会话上传同一文件/目录。
- 每个目标独立进度、冲突策略和错误。
- 全局并发上限同时约束服务器数和文件任务数。
- 结果汇总可复制，但路径和主机按诊断策略脱敏。

## 6. 服务器监控

### 6.1 采集模型

```ts
interface ServerMetricsSnapshot {
  sessionId: string
  capturedAt: string
  uptimeSeconds?: number
  load?: [number, number, number]
  cpuPercent?: number
  memory?: { total: number; used: number; available: number }
  disks?: Array<{ mount: string; total: number; used: number }>
  network?: { receivedBytes: number; transmittedBytes: number }
}
```

- 采集通过独立 exec channel 或明确隔离通道，不能向交互 Shell 注入命令。
- 远端命令固定、可审计，不拼接用户输入。
- 默认采集周期保守，可关闭；面板隐藏时降频或停止。
- 不支持的系统指标显示不可用，不把部分失败判为连接失败。

### 6.2 展示与资源

- 展示当前值和短时趋势，不建立长期历史数据库。
- 采集任务具备超时、取消和单会话互斥。
- 20 个目标同时监控时限制并发和 IPC 更新频率。
- 监控关闭、会话关闭和应用退出立即停止采集。
- 不上传指标，不默认写入诊断日志。

## 7. 远程文本编辑

### 7.1 打开与限制

- 从 SFTP 文件列表打开普通文件。
- 第一版只支持 UTF-8、小于配置上限的文本文件。
- 检测 NUL 或二进制特征时拒绝文本编辑并建议下载。
- 展示路径、大小、权限和最后修改时间。

### 7.2 编辑与保存

- 支持语法高亮、查找、替换、撤销和未保存标记。
- 打开时记录修改时间、大小和内容哈希。
- 保存前重新读取元数据；远端已变化时提示冲突。
- 支持重新加载、另存副本或用户明确覆盖。
- 保存使用远端临时文件加 rename，尽量保留原权限。
- 关闭未保存文件必须确认。

## 8. 错误码

至少覆盖：

```text
QUICK-COMMAND-TEMPLATE-INVALID
QUICK-COMMAND-PARAMETER-MISSING
BROADCAST-NO-TARGETS
BROADCAST-PARTIAL-FAILURE
MONITOR-UNSUPPORTED
MONITOR-COLLECTION-FAILED
REMOTE-EDIT-FILE-TOO-LARGE
REMOTE-EDIT-NOT-TEXT
REMOTE-EDIT-CONFLICT
REMOTE-EDIT-SAVE-FAILED
```

## 9. 安全要求

- 快速命令不执行模板表达式、不访问本地环境变量和文件。
- 立即执行、广播和批量分发必须由用户明确触发。
- 广播模式持续可见，不能因切换标签静默保留危险状态。
- secret 参数不保存、不记录、不复制到结果摘要。
- 监控命令固定且无用户输入插值。
- 远程编辑不通过 Shell 写文件，不静默覆盖并发修改。
- 所有远端文本、路径和监控输出按不可信数据解析并限制大小。

## 10. 测试与验证

- 快速命令 CRUD、搜索、模板解析、缺失参数和秘密历史排除。
- 单行、多行、特殊字符和 Unicode 参数的最终预览。
- 20 会话连接、部分失败、广播退出和控制序列。
- 并发上传到多个目标的限流、取消和汇总。
- Ubuntu、Debian、Rocky Linux 的监控解析和缺失工具降级。
- 20 目标监控时 CPU、内存、IPC 频率和终端响应。
- UTF-8、空文件、只读文件、二进制、大文件和远端并发修改。
- 编辑保存网络中断不破坏原文件，临时文件按策略清理。
- 日志、导出和命令历史秘密扫描。

## 11. 任务拆分

1. 模板语法、广播威胁模型和监控协议评审。
2. QuickCommand schema、迁移、解析器和单元测试。
3. 快速命令管理与参数预览 UI。
4. 并发会话控制器和显式广播。
5. 多目标 TransferRegistry 调度与汇总。
6. 监控采集、解析、限流和面板。
7. 远程文本读取、编辑、冲突和原子保存。
8. 20 会话压力、安全和跨系统验收。

## 12. 阶段交付物

- 快速命令模板和数据模型文档。
- 并发会话、广播和批量文件分发。
- 服务器监控采集协议与展示。
- 远程文本编辑和冲突保护。
- 压力、安全、跨 Linux 发行版和用户验收记录。
- 更新后的核心替代版发布说明和已知限制。

## 13. 退出条件

- 快速命令在预览、粘贴和立即执行之间无歧义。
- 广播默认关闭、目标明确、退出可靠且不记录命令正文。
- 20 会话并发和监控压力测试保持终端可交互。
- 批量文件分发遵守并发上限并提供逐目标结果。
- 远程编辑能检测并发修改，失败不破坏原文件。
- 所有秘密扫描零命中，无阻断级或严重级缺陷。
