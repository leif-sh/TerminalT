# 阶段 8 实施进度：网络路径与 SSH 隧道

## 完成状态（0.1.0-13）

阶段 8 已完成。TerminalT 现已具备代理、多跳 SSH、连接租约复用和三类 SSH 隧道的完整运行闭环，阶段验收记录见 [阶段 8 验收](../testing/STAGE_8_ACCEPTANCE.md)。

## 已交付能力

### 网络路径与安全

- HTTP CONNECT：无认证、Basic 认证、16 KiB 响应头上限及连接、认证、协议错误分类。
- SOCKS5：无认证和用户名密码认证，支持域名、IPv4 与 IPv6。
- 代理密码仅存入 CredentialVault；持久化数据、导入导出、复用键和日志均不含明文秘密。
- 有序 Jump Host 引用支持嵌套展开，保存时拒绝重复、失效引用、自引用和间接循环。
- 实际 SSH 链路逐跳使用 `direct-tcpip` 建立，支持“代理 → Jump A → Jump B → 目标服务器”。
- 每一跳使用独立 known-host 记录；未信任或指纹变化的跳板会在进入下一跳前阻断链路。
- 连接进度展示当前跳数，失败信息携带脱敏的跳序号和稳定错误码。

### 连接复用与生命周期

- 显式 `ConnectionPool` 按保存连接、目标/逐跳指纹、认证与代理元数据生成复用键。
- 终端、SFTP 和隧道通过独立 `ConnectionLease` 共享同一 SSH 传输。
- 配置或主机指纹变化会生成新复用键，不继续使用旧传输。
- 终端关闭不会中断仍持有租约的隧道；最后一个租约释放后按顺序关闭目标和上游连接。
- 应用退出时有界停止隧道、关闭会话、取消操作并清理连接池。

### SSH 隧道

- 本地转发 `-L`：每个入站 TCP 连接建立到固定目标的 `direct-tcpip` channel。
- 远程转发 `-R`：注册远端监听，路由 `forwarded-tcpip` 到本地目标，并在停止时撤销监听。
- 动态转发 `-D`：本地 SOCKS5 服务端，仅允许 TCP CONNECT，拒绝 UDP ASSOCIATE。
- `TunnelRegistry` 管理不可猜测 runtime ID、启停状态、取消、活动连接数、双向字节数和最近错误。
- 单规则并发连接数上限为 100；完成的子任务会及时回收，重复启动不会累积过期运行项。
- 本地与动态转发默认绑定 loopback；所有远程转发及非 loopback 监听均需风险确认并持续显示高风险标记。

### 管理界面

- 支持规则新建、编辑、复制、删除、启动和停止。
- 每秒同步运行态，并接收状态事件；展示监听地址、目标、状态、活动连接、流量和最近错误。
- 删除运行中规则会先明确告知连接中断风险，再停止运行实例并删除规则。
- 远程转发持续提示 GatewayPorts/防火墙带来的暴露风险。

## 阶段结论

功能、并发、重复启停、多跳指纹阻断、连接复用和安全边界均已有自动化验证。真实公网、企业代理和特定 SSH 服务端策略仍属于发布前兼容性矩阵，不阻塞阶段 8 的功能退出。
