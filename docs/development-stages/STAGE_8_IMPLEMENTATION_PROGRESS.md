# 阶段 8 实施进度：网络路径与 SSH 隧道

## 当前增量（0.1.0-12）

本增量建立阶段 8 的可运行基础，覆盖代理、网络路径配置、三类隧道的持久化与运行态管理。

### 已实现

- HTTP CONNECT 客户端：无认证、Basic 认证、16 KiB 响应头上限、连接/认证/协议错误分类。
- SOCKS5 客户端：无认证和用户名密码认证，支持域名、IPv4、IPv6。
- 代理密码只进入 CredentialVault；连接 JSON、导入导出和日志均不保存明文。
- 连接配置支持有序 Jump Host 引用，保存时拒绝重复、失效引用、自引用和间接循环。
- 隧道规则 schema 3 迁移、CRUD、导入导出、连接删除保护和非 loopback 风险确认。
- TunnelRegistry 管理不可猜测 runtime ID、启停状态、取消、连接数与双向字节统计。
- 本地转发（`-L`）、远程转发（`-R`）和动态 SOCKS5（`-D`，仅 TCP CONNECT）。
- 远程 `forwarded-tcpip` 回调按监听地址/端口路由到本地目标。
- 单个 SSH 连接复用终端、SFTP 和多个隧道；终端关闭时保留仍被隧道持有的连接租约。
- 手动启动与“随连接启动”策略；应用退出时先有界停止隧道，再关闭会话。
- 隧道管理页：规则新建、编辑、删除、启停、状态、活动连接和流量展示。

### 安全边界

- 本地和动态转发默认绑定 `127.0.0.1`；非回环地址必须二次确认。
- 动态转发拒绝 SOCKS5 UDP ASSOCIATE 和非 CONNECT 命令。
- 单条规则并发连接数上限为 100，SOCKS5 握手超时为 10 秒。
- 远程监听失败、端口占用、目标连接失败和停止失败使用稳定错误码。

## 后续增量

阶段 8 尚需继续完成以下退出条件：

1. 将已保存的单跳/多跳引用接入实际 SSH Connector，并为每一跳提供独立指纹确认与认证交互。
2. 将当前会话内租约提升为显式 ConnectionPool，补齐配置变更后的复用键失效策略。
3. 增加 `-L/-R/-D` loopback 拓扑、100 并发、100 次重复启停、断网和三跳集成测试。
4. 在隧道页补充复制规则、最近错误详情和远程 GatewayPorts 持续风险提示。

当前增量不宣告阶段 8 退出条件全部完成；它是后续多跳与压力验收的稳定基线。
