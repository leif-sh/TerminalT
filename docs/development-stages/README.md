# TerminalT 阶段开发文档

本目录将 TerminalT 基础版与后续核心替代版范围拆分为可独立计划、开发和验收的阶段。阶段 0～6 是已完成的基础版，阶段 7～12 来自《TerminalT 总体开发文档》的后续路线图。开发应按依赖推进；允许并行的阶段仍需满足各文档列出的前置条件和接口约束。

## 执行规则

1. 每个阶段开始前，确认上一阶段的退出条件已经满足。
2. 功能开发必须同时完成对应的异常路径、资源释放和测试，不把这些工作推迟到后续发布阶段。
3. 阶段 6 是基础版系统级加固；阶段 10 是后续签名更新与发布能力，两者都不替代各功能阶段自身验收。
4. 未列入总体开发文档的能力不得顺带实现；新增范围必须先更新总体文档和对应阶段文档。
5. 前端、Rust 后端和测试任务应围绕同一个稳定数据模型与错误码契约开发。
6. 阶段 7 启动前必须恢复 `AGENTS.md` 引用但当前缺失的前端、Rust 和提交前 CI 规范。

## 阶段状态建议

每个阶段可使用以下状态管理：

- `未开始`：前置条件未满足或尚未排期；
- `开发中`：功能与自动化测试正在实现；
- `联调中`：前后端契约稳定，正在进行真实服务器验证；
- `验收中`：功能冻结，只修复本阶段缺陷；
- `已完成`：退出条件全部满足且无阻断级、严重级缺陷。
