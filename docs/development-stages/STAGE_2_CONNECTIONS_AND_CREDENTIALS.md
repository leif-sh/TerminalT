# 阶段 2：连接资产与安全凭据

## 1. 阶段目标

将阶段 1 的临时连接能力升级为可长期使用的连接资产管理功能，并通过操作系统安全凭据库存储用户明确授权保存的密码和私钥口令。

## 2. 前置条件

- 阶段 1 的 SSH 连接、认证和主机密钥流程稳定。
- 已确定本地数据库或结构化配置存储方案及迁移机制。
- 已确定 Windows 凭据库集成方案和不可用时的降级行为。

## 3. 对应需求

- `FR-CONN-001` 至 `FR-CONN-004`。
- `FR-SSH-002`、`FR-SSH-003` 中的安全保存部分。
- `FR-SSH-004` 的主机密钥持久化。
- `FR-SET-001` 中的历史和主机指纹清理入口将在阶段 5 补齐设置页入口。

## 4. 详细开发功能

### 4.1 连接配置存储

- 按 `ConnectionProfile` 模型持久化非敏感连接信息。
- 使用不可猜测 ID，并保存创建时间、更新时间和最后成功连接时间。
- 私钥认证只保存私钥路径和凭据引用，不保存私钥内容。
- 密码认证只保存凭据引用，不在普通数据库保存密码。
- 数据写入使用事务或原子替换，避免异常退出损坏全部配置。
- 建立 schema 版本字段和迁移入口。
- 应用启动时处理数据文件不存在、数据为空和可恢复损坏等状态。

### 4.2 新建和编辑连接

- 完整实现连接名称、主机、端口、用户名、认证方式、分组和备注字段。
- 连接名称默认为主机名，限制为 1～64 个字符。
- 用户名限制为 1～128 个字符，备注最多 500 个字符。
- 支持密码“仅本次使用”和“记住密码”。
- 支持私钥口令“仅本次使用”和“记住口令”。
- 保存前验证私钥路径；连接前再次验证文件可读性。
- 表单继续提供“测试连接”和“保存”。
- 编辑保存后立即刷新列表，但不修改或重启已建立会话。

### 4.3 连接列表

- 展示连接名称、主机地址、用户名和在线会话状态。
- 按分组组织连接，并提供默认分组。
- 单击选中，双击发起连接。
- 更多菜单提供连接、编辑、复制和删除。
- 复制连接生成新 ID，并对名称做清晰的副本标记。
- 删除前显示连接名称和后果确认。
- 删除连接配置不得关闭已建立的会话。
- 删除连接不得删除用户选择的私钥文件。
- 支持按最后成功连接时间排序。

### 4.4 搜索

- 输入后即时过滤连接列表。
- 搜索范围包含连接名称、主机地址、用户名和备注。
- 搜索不区分大小写，并忽略查询首尾空格。
- 搜索结果保留所属分组信息和在线状态。
- 清除搜索后恢复原分组和排序状态。

### 4.5 分组管理

- 支持新建、重命名和删除单层分组。
- 连接可在编辑表单中切换分组。
- 删除空分组时直接删除分组记录。
- 删除非空分组前显示迁移提示，确认后将连接移动到默认分组。
- 默认分组不可删除，并提供稳定的内部标识。
- 分组名称为空、重名或超限时显示字段错误。

### 4.6 快速连接

- 提供独立快速连接入口。
- 解析 `user@host` 和 `user@host:port`。
- 对 IPv6 等含冒号地址制定无歧义输入规则并给出错误提示。
- 用户补充密码或私钥信息后直接建立会话。
- 关闭后不保存连接配置、密码或口令。
- 如果保留最近目标，只保存脱敏目标地址，不保存认证信息。
- 为阶段 5 的“清除最近历史”入口提供存储接口。

### 4.7 系统凭据库

- 仅在用户主动勾选记住凭据时写入 Windows 安全凭据库。
- 普通数据库只保存不可直接获取秘密的引用标识。
- 更新凭据时替换旧值，切换认证方式时清理不再使用的凭据。
- 删除连接时清理该连接独占的凭据记录。
- 凭据库不可用、访问被拒绝或记录丢失时提示重新输入，不回退为明文存储。
- 仅本次凭据只存在于必要的运行期内存中，失败、取消和断开时清理。
- 错误和日志不得输出凭据值或包含秘密的调试结构。

### 4.8 主机密钥记录

- 将主机、端口、算法、指纹、公钥和信任时间持久化。
- 对同一主机不同端口分别记录。
- 支持读取、添加、替换和删除记录的服务接口。
- 替换旧指纹必须经过明确的高风险确认。
- 为阶段 5 的已保存指纹管理页提供查询和清理接口。

## 5. 测试与验证

- 覆盖连接新建、编辑、复制、删除、排序和重启恢复。
- 覆盖名称、主机、端口、用户名、备注和私钥路径校验。
- 覆盖分组新建、重命名、删除及非空分组迁移。
- 覆盖名称、主机、用户名和备注搜索。
- 覆盖快速连接的有效和无效格式。
- 验证记住密码、记住口令、更新和删除凭据。
- 模拟凭据库不可用或凭据记录丢失，确认不会明文降级。
- 检查数据库、配置、日志和错误详情中不存在明文秘密。
- 模拟数据写入中断，确认已有连接配置仍可读取。

## 6. 阶段交付物

- 完整连接管理页面和分组搜索功能。
- 连接、分组和主机密钥持久化服务。
- Windows 系统凭据库集成。
- 快速连接入口及脱敏历史存储接口。
- 数据模型迁移和安全测试。

## 7. 退出条件

- 应用重启后可以安全复用已保存连接。
- 编辑连接不影响活动会话，删除连接不关闭活动会话。
- 普通数据文件和日志不存在明文秘密。
- 凭据库异常时安全失败并要求用户重新输入。
- 连接列表、搜索和分组功能验收通过。

## 8. 本阶段不包含

- 多标签快捷键和完整终端搜索、复制粘贴设置。
- SFTP 文件管理。
- JSON 导入导出 UI。
- SSH Agent、键盘交互认证和硬件密钥。
