# 阶段 0：工程基础与架构骨架

## 1. 阶段目标

建立后续 SSH、终端和 SFTP 功能共同依赖的工程基线。阶段结束时不要求连接真实服务器，但必须能够稳定运行桌面应用，完成前后端调用、事件流、模拟会话和资源释放验证。

## 2. 前置条件

- 已确认基础版范围和 Windows 首发目标。
- 已确认技术基线为 Tauri 2、React 19、TypeScript 和 Rust。
- 已确认终端、SSH、本地数据库、系统凭据库等关键技术选型的评估标准。

## 3. 详细开发功能

### 3.1 应用外壳与信息架构

- 实现应用窗口的基础布局：左侧导航、连接侧栏、工作区。
- 左侧导航预留“连接”和“设置”两个基础版入口。
- 连接侧栏提供搜索框、分组树和连接列表占位结构。
- 工作区提供会话标签栏、终端区域和可展开 SFTP 面板的容器。
- 实现无连接、无会话、加载中和发生错误等基础页面状态。
- 建立可复用的对话框、表单控件、状态提示和危险操作确认组件。
- 所有字符串接入国际化资源；首版仅提供简体中文资源。
- 保证主要区域和操作具备键盘焦点顺序及可见焦点状态。

### 3.2 前端工程结构

- 按页面、领域组件、公共组件、状态、服务和类型划分源码目录。
- 建立连接、会话、设置、通知等状态域，避免由单个根组件维护全部状态。
- 封装 Tauri Command 调用和 Event 订阅，统一处理调用失败与取消订阅。
- 建立前端错误边界，单个视图异常不得导致整个窗口白屏。
- 建立主题变量、间距、字号、状态色等设计令牌。
- 配置 TypeScript 严格检查、Lint、格式检查和前端单元测试入口。

### 3.3 Rust 后端模块骨架

- 建立命令入口、领域服务、存储、平台能力和错误模块边界。
- 为 SSH 会话、SFTP channel 和传输任务定义不可猜测 ID 类型。
- 建立进程级会话注册表，只保存运行期状态，不持久化活动会话。
- 建立异步任务取消机制，支持关闭标签和退出应用时主动终止任务。
- 建立有界关闭流程，确保应用退出不会无限等待后台任务。
- 为后续 socket、SSH session、SFTP channel 定义明确的所有权和释放顺序。
- 配置基础日志设施，并预留敏感字段过滤层。

### 3.4 前后端通信契约

- 定义请求、响应和事件的数据格式以及版本策略。
- 实现最小健康检查命令，验证 React 到 Rust 的请求响应链路。
- 实现模拟会话创建、模拟输出、模拟 resize、模拟关闭流程。
- 终端数据事件使用二进制安全表示，不把任意字节流假设为完整 UTF-8 字符串。
- 为高频输出设计批量事件和背压策略，避免逐字符跨 IPC。
- 定义稳定错误结构，至少包含错误码、用户可映射分类、技术详情和是否可重试。
- 前端不得接收裸指针、文件句柄或可直接操作底层资源的标识。

### 3.5 核心数据模型

- 定义 `ConnectionProfile`、`HostKeyRecord`、`SessionState` 和设置模型。
- 区分持久化连接配置、运行期会话状态和临时认证输入。
- 明确密码、私钥口令只通过临时参数或凭据引用传递。
- 统一日期时间、路径、端口、ID 和可选字段的序列化规则。
- 定义数据库或配置存储的 schema 版本和迁移入口。

### 3.6 终端组件技术验证

- 接入支持 ANSI/VT、选择、搜索和 resize 的终端渲染组件。
- 使用模拟数据验证普通文本、ANSI 颜色、中文、Emoji 和宽字符显示。
- 验证键盘输入、输入法组合输入、鼠标选择和滚动缓冲。
- 验证容器尺寸改变后可产生稳定的行列数变化事件。
- 验证持续模拟输出时批量渲染，不造成明显主线程阻塞。

### 3.7 权限与安全基线

- Tauri capability 仅开放当前阶段所需命令和窗口能力。
- 文件选择、下载目录和凭据能力在实际使用阶段再按最小权限追加。
- 日志默认不记录命令参数中的敏感字段和终端数据正文。
- UI 展示的外部字符串统一按纯文本处理，禁止直接注入 HTML。
- 生产配置预留关闭开发者工具默认入口的能力。

## 4. 测试与验证

- 应用开发模式和生产构建均可启动。
- 健康检查 Command 返回符合契约的数据。
- 模拟会话可以创建、接收批量输出、调整尺寸并关闭。
- 重复创建和关闭模拟会话后，注册表中没有残留对象。
- 前端卸载组件后，相关 Event 监听全部取消。
- 模拟 Rust 错误可在前端显示本地化用户提示和技术详情。
- 基础键盘导航、焦点状态和错误边界验证通过。

## 5. 阶段交付物

- 可运行的桌面应用外壳。
- 前后端模块目录和通信封装。
- 核心数据模型及错误码契约。
- 终端组件技术验证结果。
- 模拟会话和基础自动化测试。
- 架构决策和关键依赖选择记录。

## 6. 退出条件

- Windows 环境能够稳定完成开发启动和生产构建。
- 前后端调用、事件订阅、取消和异常映射均有自动化验证。
- 模拟终端会话完整覆盖创建、输出、resize 和销毁生命周期。
- 没有会阻碍真实 SSH 实现的未决架构问题。

## 7. 本阶段不包含

- 真实 SSH 网络连接和认证。
- 连接配置持久化和系统凭据库存储。
- 多标签完整交互。
- 真实 SFTP 文件操作。
- 安装包签名和正式发布。
