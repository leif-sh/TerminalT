# 阶段 4：基础 SFTP 文件能力

## 1. 阶段目标

在当前 SSH 标签内提供精简、可靠的远端文件浏览和单文件传输能力，完成日常上传配置、下载日志和基础文件整理场景。

## 2. 前置条件

- 阶段 3 的多会话生命周期、认证复用和断线处理稳定。
- SSH 服务可以为当前会话安全创建并销毁 SFTP channel。
- 本地文件选择与保存目录的 Tauri 最小权限方案已确认。

## 3. 对应需求

- `FR-SFTP-001` 至 `FR-SFTP-003`。
- 第 6.6 节中的权限不足、网络中断等文件操作错误。

## 4. 详细开发功能

### 4.1 SFTP 面板与会话绑定

- SFTP 面板依附于当前 SSH 标签，并可展开或收起。
- 共用连接的主机、端口、认证和主机信任信息。
- 每个 SSH 标签拥有独立 SFTP 状态，不混用路径和任务。
- 仅在用户首次打开面板时按需创建 SFTP channel。
- SSH 会话断开时停止新的文件操作，并将进行中任务转为失败或取消。
- 关闭标签时取消并释放对应 SFTP channel 和传输任务。

### 4.2 远端目录浏览

- 首次打开默认进入远端用户 Home 目录。
- 显示文件名、类型、大小、修改时间和 Unix 权限。
- 支持进入目录、返回上级、输入路径跳转和刷新。
- 显示当前规范化路径和目录加载状态。
- 文件列表默认目录优先，再按名称排序。
- 权限不足或路径不存在时保留最近可用路径并显示错误。
- 对 5,000 个条目的目录异步加载和分批渲染，不阻塞整个窗口。
- 远端路径和文件名只按文本展示并正确转义。

### 4.3 上传文件

- 通过系统文件选择器选择一个本地文件上传到当前目录。
- 创建任务前读取文件大小和目标路径，但不一次性载入整个文件。
- 分块读取本地文件并写入远端。
- 同名目标存在时，在传输前显示覆盖确认。
- 覆盖操作尽量使用临时目标和完成后替换，避免失败破坏已有文件。
- 权限不足、空间不足、连接中断和本地读取失败时返回可读错误。
- 上传成功后刷新或增量更新当前目录。

### 4.4 下载文件

- 用户选择本地目标目录后下载单个远端文件。
- 分块读取远端文件并写入本地临时文件。
- 本地存在同名文件时，在传输前确认覆盖。
- 下载成功后再完成目标文件替换。
- 失败或取消时清理临时文件，不破坏已有目标文件。
- 本地路径无权限、磁盘空间不足和远端读取失败时返回可读错误。
- 默认下载目录由阶段 5 的设置管理，本阶段提供调用接口和合理默认值。

### 4.5 基础文件操作

- 在当前目录新建文件夹。
- 对单个文件或目录重命名。
- 删除单个文件。
- 删除空目录。
- 覆盖、重命名冲突和删除操作均需明确提示对象名称。
- 删除前说明远端删除通常不可恢复。
- 后端重新验证目标类型，不仅依赖前端显示结果。
- 基础版拒绝非空目录递归删除，并返回明确说明。

### 4.6 传输任务模型

- 每个任务包含不可猜测 ID、文件名、方向、源、目标、已传输大小、总大小、速度和状态。
- 状态至少包含排队中、进行中、成功、失败和已取消。
- 同时最多执行 3 个上传或下载任务，其余进入 FIFO 队列。
- 前端通过节流进度事件更新，不为每个数据块触发高频渲染。
- 速度使用稳定时间窗口计算，未知总大小时不显示误导性百分比。
- 完成状态保留在当前会话任务列表中，用户可清理已完成项。

### 4.7 取消和重试

- 排队任务可直接取消并从待执行队列移除。
- 进行中任务取消时中止 I/O、关闭相关句柄并清理临时文件。
- 取消与自然完成竞争时保证只产生一个最终状态。
- 失败任务显示可读原因，并允许使用原源和目标重新创建任务。
- 重试覆盖任务前重新检查目标状态，必要时再次请求确认。
- SSH 会话失效后禁止直接重试，先提示用户重新连接。

### 4.8 路径与安全处理

- 远端路径始终作为 SFTP 参数处理，不拼接到本地 shell 命令。
- 规范化当前路径、父路径和目标路径，防止 UI 状态与实际操作目标不一致。
- Windows 本地路径使用平台路径 API，不手工假设分隔符。
- 文件名、服务器错误和路径不得以未经转义的 HTML 展示。
- 日志可记录任务结果和必要路径，但不得记录认证信息或文件正文。

## 5. 测试与验证

- 覆盖 Home 目录、空目录、无权限目录、路径不存在和 5,000 条目目录。
- 覆盖上传、下载、覆盖确认、取消、失败和重试。
- 覆盖新建目录、重命名、删除文件和删除空目录。
- 验证非空目录删除被拒绝。
- 同时提交超过 3 个任务，确认并发上限和排队顺序。
- 在传输中断网、关闭标签和退出应用，确认资源及临时文件正确清理。
- 验证上传或下载失败不会破坏已有目标文件。
- 使用特殊字符、中文和疑似 HTML 的文件名测试安全展示。

## 6. 阶段交付物

- 标签内 SFTP 文件面板。
- Rust SFTP 浏览和文件操作服务。
- 最多 3 并发的传输任务队列。
- 进度、取消、失败重试及临时文件保护机制。
- SFTP 端到端与异常测试记录。

## 7. 退出条件

- 基础浏览、上传、下载、新建、重命名和删除稳定可用。
- 传输失败或取消不会破坏已有文件。
- 大目录与传输进度不会阻塞 SSH 终端和整个窗口。
- 关闭标签或应用后无残留 SFTP 任务和文件句柄。
- 阶段范围内无阻断级或严重级缺陷。

## 8. 本阶段不包含

- 双栏文件管理器和远程在线编辑。
- 非空目录递归删除和批量文件操作。
- 断点续传、拖拽传输和跨会话任务迁移。
- 权限修改、所有者修改和软链接创建。
