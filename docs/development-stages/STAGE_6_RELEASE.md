# 阶段 6：稳定性、安全与发布

## 1. 阶段目标

对功能完整版本进行系统级性能、稳定性、安全和 Windows 交付验证，修复发布阻断问题，产出可安装、可升级、可卸载的 FastTerm 基础版 v1.0。

## 2. 前置条件

- 阶段 0～5 全部功能完成并通过各自退出条件。
- 功能进入冻结状态，除缺陷修复外不再增加基础版范围。
- 已准备受支持服务器、网络故障注入、长稳测试和 Windows 安装测试环境。

## 3. 验收范围

- 第 10 节全部安全要求。
- 第 11 节性能、稳定性、可用性与无障碍要求。
- 第 12 节测试矩阵和发布验收条件。
- Windows 安装、签名、升级和卸载流程。

## 4. 详细开发与验证内容

### 4.1 功能回归

- 回归连接新建、编辑、复制、删除、搜索和分组。
- 回归密码、无口令私钥和带口令私钥认证。
- 回归首次主机指纹、匹配、变化阻断和记录删除。
- 回归单会话、多会话、连接中取消、断线和重连。
- 回归复制粘贴、搜索、显示设置和快捷键。
- 回归 SFTP 浏览、上传、下载、覆盖、取消、重试、重命名和删除。
- 回归设置、导入导出、日志和数据清理。
- 确认所有明确排除的基础版外功能没有形成不完整入口。

### 4.2 服务器与认证兼容性

- 在 Ubuntu LTS、Debian、Rocky Linux/OpenSSH Server 上完成端到端验证。
- 覆盖 RSA、ECDSA、Ed25519 私钥的支持矩阵。
- 覆盖不同主机密钥算法和常见安全默认配置。
- 对不支持的旧算法返回清晰错误，不静默开启弱算法。
- 验证 IPv4、IPv6 和域名连接行为。
- 记录已知兼容限制并形成发布说明。

### 4.3 网络异常与恢复

- 测试 DNS 失败、TCP 超时、连接拒绝和握手失败。
- 测试认证中断网、Shell 使用中断网和传输中断网。
- 测试服务器主动关闭、空闲超时和系统休眠恢复。
- 验证每种异常的状态转换、用户提示、可重试性和资源释放。
- 验证重连始终建立全新 Shell，不错误暗示恢复远端进程状态。
- 验证临时凭据在异常后不会被无提示复用。

### 4.4 性能验证与优化

- 主流 Windows 设备冷启动到主窗口不超过 3 秒。
- 除网络和认证耗时外，点击已保存连接到终端的应用额外开销不超过 500 ms。
- 单会话持续接收 5 MB 日志输出时界面可交互且不崩溃。
- 同时保持 10 个空闲 SSH 会话，标签切换无明显卡顿。
- SFTP 列出 5,000 个文件时不阻塞整个窗口。
- 分析 IPC 批量大小、前端渲染、内存缓冲和任务调度瓶颈。
- 优化必须保持数据完整性和安全边界，不通过取消校验换取性能。

### 4.5 长时间稳定性

- 运行至少 8 小时 SSH 长连接，监测内存、句柄、任务和 CPU 趋势。
- 重复执行连接、断开、重连和关闭标签，检查资源累计。
- 重复打开和关闭 SFTP 面板及传输任务，检查 channel 和文件句柄泄漏。
- 测试关闭应用时有界等待所有 SSH/SFTP 任务。
- 验证单个会话 panic 或错误不会导致其他会话断开或应用退出。
- 模拟异常退出，确认连接和设置数据仍可读取。

### 4.6 敏感信息审计

- 扫描数据库、普通配置、日志、导出文件和崩溃信息。
- 确认不存在密码、私钥内容、私钥口令和完整认证报文。
- 验证私钥未被复制、修改或包含在备份中。
- 验证仅在用户主动授权时写入系统凭据库。
- 验证临时凭据在测试连接、认证失败、取消和关闭后被释放。
- 检查错误链和调试格式，防止底层库意外输出敏感参数。

### 4.7 SSH 安全审计

- 首次主机密钥必须经过用户确认。
- 已记录主机指纹变化必须默认阻断连接。
- 核对新旧指纹展示和替换记录的明确确认流程。
- 确认只支持 SSH-2，且不默认开启已知弱算法。
- 验证连接测试与正式连接使用一致的主机校验策略。
- 验证所有 socket、session 和 channel 的取消与关闭路径。

### 4.8 应用与文件安全审计

- 审计 Tauri Command 白名单和 capability，移除未使用权限。
- 生产包关闭开发者工具默认入口。
- 远端路径、文件名、错误内容按不可信输入处理。
- 验证任何远端输入都不会被拼接成本地命令。
- 粘贴多行或超过 1,000 字符的内容必须确认。
- 应用升级或崩溃后不得恢复并发送未提交终端输入。
- 删除和覆盖操作必须展示具体对象及不可恢复后果。

### 4.9 数据完整性与升级

- 验证所有设置和连接写入使用事务或原子替换。
- 模拟磁盘写入失败、进程终止和数据文件部分损坏。
- 验证旧 schema 到当前 schema 的迁移。
- 迁移失败时保留原始数据并提供可诊断错误。
- 验证导入不会覆盖同 ID 连接。
- 验证版本升级不会丢失连接、分组、主机密钥和设置。

### 4.10 可用性与无障碍

- 主要连接、终端、SFTP 和设置操作均可通过键盘完成。
- 状态除颜色外同时使用图标或文字表达。
- 所有危险操作明确对象名称和后果。
- 对话框焦点进入、循环和关闭后恢复正确。
- 错误对话框提供复制技术详情入口。
- 检查常见 Windows 显示缩放下的布局和文本可读性。

### 4.11 Windows 安装包

- 配置正式应用名称、图标、版本、发布者和安装标识。
- 生成生产构建并完成代码签名。
- 在干净 Windows 环境验证首次安装和启动。
- 验证覆盖升级保留用户数据和系统凭据引用。
- 验证卸载流程；明确用户数据是否保留并向用户提示。
- 验证重复安装、升级失败回滚和卸载后重装。
- 确认安装包不包含开发测试文件、秘密或多余权限。

### 4.12 发布准备

- 整理版本说明、系统要求、已知限制和安全说明。
- 确认基础版不支持项与产品文档一致。
- 汇总自动化测试、手工测试、性能和安全审计结果。
- 所有阻断级和严重级缺陷必须清零。
- 中低等级遗留问题必须评估影响、规避方式和修复计划。
- 对最终安装包记录哈希并归档构建来源和签名信息。

## 5. 最低测试矩阵

| 类别 | 最低覆盖 |
| --- | --- |
| 服务器 | Ubuntu LTS、Debian、Rocky Linux/OpenSSH Server |
| 网络 | 正常、DNS 失败、拒绝、超时、中途断网、服务器关闭 |
| 认证 | 正确/错误密码，无口令/带口令 RSA、ECDSA、Ed25519 私钥 |
| 主机密钥 | 首次、匹配、变化、替换、删除后重连 |
| 终端 | vim、top、less、tmux、中文输入、彩色输出、窗口缩放 |
| 多会话 | 10 个空闲会话、单会话失败、取消、关闭、手动重连 |
| SFTP | 浏览、无权限、上传、下载、覆盖、取消、重试、删除 |
| 数据 | 新建、编辑、复制、删除、搜索、分组、导入、导出、升级 |
| 安全 | 秘密扫描、指纹变化阻断、多行粘贴、权限审计 |
| 安装 | 干净安装、覆盖升级、卸载、重装 |

## 6. 阶段交付物

- 完整回归和兼容性测试报告。
- 性能基准和 8 小时长稳测试报告。
- 敏感信息、SSH 和 Tauri 权限安全审计结果。
- 数据迁移、安装、升级和卸载验证结果。
- 签名的 Windows 安装包、文件哈希和发布说明。

## 7. 发布退出条件

- 总功能文档所有纳入项完成。
- 密码和私钥认证通过端到端测试。
- 主机密钥首次确认和变化阻断有效。
- 终端可稳定运行常见全屏程序。
- SFTP 基础操作可靠，失败不会破坏原文件。
- 应用退出后无残留 SSH 连接或后台传输。
- 配置、日志、导出和安装包中未发现认证秘密。
- Windows 签名、安装、升级和卸载验证通过。
- 无阻断级或严重级缺陷。

## 8. 本阶段不包含

- 临近发布新增高级 SSH、SFTP 或其他协议功能。
- SSH Agent、跳板机、端口转发和云同步。
- 分屏、会话录制、远程编辑和断点续传。
- RDP、Telnet、Serial、Mosh、AI 和插件系统。
