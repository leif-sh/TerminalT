# 阶段 5：设置、数据迁移与诊断

## 1. 阶段目标

补齐应用级设置、连接配置备份恢复和可诊断日志，使用户能够管理本地数据，并使测试和支持人员可以在不泄露敏感信息的前提下定位问题。

## 2. 前置条件

- 阶段 4 前的连接、会话、终端和 SFTP 设置接口已经稳定。
- 本地数据存储具备 schema 版本和原子写入能力。
- Rust 错误码已经覆盖 SSH 与 SFTP 主要失败路径。

## 3. 对应需求

- `FR-SET-001` 至 `FR-SET-003`。
- 第 6.6 节错误反馈的完整呈现。
- `FR-TERM-005` 中需要统一管理的全局显示设置。

## 4. 详细开发功能

### 4.1 设置页结构

- 设置按通用、终端、连接、安全与数据、日志等区域组织。
- 设置项显示当前值、默认值、有效范围和生效时机。
- 输入超出范围时就地提示并禁止保存。
- 设置保存失败时保留用户输入，并显示可复制技术详情。
- 支持按设置域恢复默认值，危险清理操作不得混入普通恢复默认。

### 4.2 窗口与通用设置

- 保存并恢复上次窗口大小和位置。
- 恢复前校验窗口是否仍处于可用显示器范围，避免窗口出现在屏幕外。
- 简体中文作为基础版唯一语言，但继续使用国际化资源管理。
- 保存关闭活动会话时是否确认的设置。
- 保存默认下载目录，并验证目录存在性和可写性。
- 默认目录失效时回退到系统下载目录并提示用户。

### 4.3 连接行为设置

- 连接超时范围 5～60 秒，默认 15 秒。
- Keepalive 默认 30 秒，并支持关闭。
- 修改后的设置应用于新连接；已建立会话如可安全更新则即时应用。
- 对无法即时应用的设置明确标记“新会话生效”。
- 设置值通过统一配置服务提供给 SSH 和 SFTP 模块，不由各模块重复读取文件。

### 4.4 终端全局设置整合

- 在设置页集中管理字体、字号、行高、主题、光标和滚动缓冲。
- 复用阶段 3 的校验范围和运行期更新机制。
- 展示设置预览，预览不创建真实 SSH 会话。
- 设置变更失败时回滚到最后有效配置。

### 4.5 历史和主机指纹管理

- 展示快速连接的脱敏最近历史。
- 支持清除全部最近连接历史，并在操作前确认。
- 展示已保存主机指纹的主机、端口、算法、指纹和信任时间。
- 支持删除单条主机指纹和清除全部记录。
- 删除操作明确说明下次连接会重新要求确认服务器身份。
- 清除指纹不得删除连接配置或系统凭据。

### 4.6 连接配置导出

- 将连接与分组导出为带格式版本号的 JSON 文件。
- 默认不包含密码、私钥口令、凭据引用的可解析秘密和私钥内容。
- 私钥配置只可包含本地路径，并在导出提示中说明跨设备可能失效。
- 导出前允许用户选择目标路径；同名文件覆盖前确认。
- 使用临时文件和原子替换，避免失败留下半个 JSON 文件。
- 导出完成后显示连接数量、分组数量和文件位置。

### 4.7 连接配置导入

- 导入前验证 JSON 语法、格式版本、字段类型和字段范围。
- 无法识别的未来版本安全拒绝，并给出版本提示。
- 对缺失的可选字段应用默认值，对必填字段缺失逐项报告。
- 同 ID 连接生成新 ID，绝不覆盖现有连接。
- 重名连接允许导入，但在结果中提示重名。
- 分组重名时复用或创建的规则保持确定性并写入文档。
- 私钥路径不存在时仍可导入，但标记需要用户修正。
- 导入采用事务；严重校验失败时不产生部分导入。
- 完成后显示成功、跳过、重命名和失败项目汇总。

### 4.8 诊断日志

- 记录应用启动、关闭、版本和运行平台信息。
- 记录 SSH 连接阶段、稳定错误码和耗时。
- 记录 SFTP 任务方向、结果、耗时和错误码。
- 不记录终端输入输出正文。
- 不记录密码、私钥内容、私钥口令或完整认证报文。
- 日志允许保留用户名和主机用于诊断，并在设置页明确告知。
- 默认保留最近 7 天并限制总大小，超限时按最旧优先清理。
- 提供打开日志目录、复制日志位置和手动清理日志的入口。
- 日志查看或导出前再次执行敏感字段过滤。

### 4.9 错误详情体验

- 所有用户错误展示简明原因和建议操作。
- 可展开区域展示时间、错误码、阶段、是否可重试和技术详情。
- 提供一键复制技术详情，复制内容先经过敏感信息过滤。
- 相同短时间错误避免生成大量重复通知，但日志仍保留必要计数。
- 危险类错误如主机密钥变化使用独立高风险视觉和阻断流程。

## 5. 测试与验证

- 验证窗口恢复在单屏、多屏、分辨率变化和显示器移除后的行为。
- 覆盖所有设置的边界值、无效值、持久化和生效时机。
- 导出文件执行密码、口令、私钥内容和敏感引用扫描。
- 覆盖导入有效、语法错误、字段错误、未来版本、同 ID 和重名情况。
- 模拟导入中断，确认事务不会留下部分数据。
- 制造 SSH、SFTP 和设置错误，验证用户提示与技术详情。
- 运行终端和传输任务后检查日志不包含正文或秘密。
- 验证 7 天保留和总大小限制清理策略。

## 6. 阶段交付物

- 完整设置页和统一设置服务。
- 最近历史和主机指纹管理界面。
- 版本化 JSON 导入导出功能。
- 诊断日志、轮转、清理和错误详情复制能力。
- 数据迁移与敏感信息扫描测试。

## 7. 退出条件

- 设置项能够可靠保存、恢复并按声明时机生效。
- 导入导出不会包含或覆盖敏感凭据。
- 日志满足诊断需求且不记录终端正文和认证秘密。
- 核心错误均有用户提示和经过脱敏的技术详情。
- 阶段范围内无阻断级或严重级缺陷。

## 8. 本阶段不包含

- 账号体系、云同步和团队共享。
- 自动上传日志或崩溃报告。
- 私钥文件或密码随导出文件迁移。
- 多语言内容翻译，仅保证国际化结构。
