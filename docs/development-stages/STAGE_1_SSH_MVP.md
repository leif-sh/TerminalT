# 阶段 1：SSH 单会话最小闭环

## 1. 阶段目标

实现从填写连接信息到进入远程交互式 Shell 的第一条真实业务闭环。阶段结束时，用户可以使用密码或私钥连接受支持的 OpenSSH 服务器，并在单个终端标签中完成基本命令行操作。

## 2. 前置条件

- 阶段 0 的前后端通信、任务取消、错误结构和终端组件验证完成。
- 已确定维护中的 Rust SSH 库，并验证其许可证、算法支持和异步模型。
- 准备 Ubuntu LTS、Debian 和 Rocky Linux/OpenSSH Server 测试环境。

## 3. 对应需求

- `FR-CONN-001` 中的连接表单、字段校验和测试连接。
- `FR-SSH-001` 至 `FR-SSH-005` 的单会话部分。
- `FR-TERM-001` 的核心渲染、输入和 resize。
- 第 6.6 节的 SSH 核心错误反馈。

## 4. 详细开发功能

### 4.1 临时连接表单

- 支持连接名称、主机、端口、用户名和认证方式。
- 端口默认为 22，校验范围为 1～65535。
- 主机地址去除首尾空格，接受 IPv4、IPv6 和域名。
- 密码认证时要求输入密码；私钥认证时要求选择私钥路径。
- 支持输入可选的私钥口令，所有敏感输入默认遮挡。
- 校验错误显示在对应字段附近，错误时禁止提交。
- 提供“测试连接”和“连接”操作。
- 本阶段表单数据只存在内存中，不实现连接配置持久化。

### 4.2 测试连接

- 依次执行 DNS、TCP、SSH 握手、主机密钥处理和认证。
- 测试成功后立即释放 socket、SSH session 和临时凭据，不创建终端。
- 返回各阶段耗时或总耗时。
- 失败时返回稳定错误码和可复制技术详情。
- 测试过程可取消；取消后界面恢复可编辑状态。

### 4.3 SSH 连接建立

- 解析主机名并建立 TCP 连接。
- 默认连接超时为 15 秒，并确保超时覆盖所有挂起连接步骤。
- 完成 SSH-2 握手和算法协商。
- 使用 SSH 库安全默认算法，不默认开启已知弱算法。
- 连接阶段向前端发送状态事件：连接中、主机密钥检查、认证中、已连接或失败。
- 用户取消或关闭标签时，取消连接任务并释放全部资源。

### 4.4 主机密钥校验

- 首次遇到未知主机时暂停连接并显示主机、端口、密钥类型和 SHA-256 指纹。
- 支持“信任并继续”和“取消”。
- 用户信任后写入本地 `known_hosts` 等价存储。
- 已知主机再次连接时自动验证指纹是否匹配。
- 指纹变化时默认阻止连接，显示新旧指纹和高风险说明。
- 只允许用户明确删除旧记录或确认替换，不提供自动忽略。
- 主机密钥等待用户操作期间支持取消并正确释放网络资源。

### 4.5 密码认证

- 将密码作为仅本次使用的内存数据提交给 Rust 认证流程。
- 认证失败后允许用户重新输入。
- 连续失败 3 次后停止自动发起认证并返回表单状态。
- UI、普通配置、错误详情和日志均不得回显密码。
- 认证结束、取消或失败后尽快释放临时密码数据。

### 4.6 私钥认证

- 支持常见 OpenSSH RSA、ECDSA 和 Ed25519 私钥。
- 支持无口令和带口令私钥。
- 文件选择器默认定位用户常用 `.ssh` 目录，但不自动扫描目录。
- Rust 仅在认证阶段读取私钥内容，不复制或写入应用数据目录。
- 分别识别文件不存在、无法读取、格式不支持和口令错误。
- 认证任务完成后释放私钥内容和临时口令。

### 4.7 PTY 与交互式 Shell

- 认证成功后请求 PTY，终端类型为 `xterm-256color`。
- 使用终端组件当前行列数作为初始 PTY 尺寸。
- 打开交互式 Shell，并将远端输出作为字节流传递给前端。
- 将前端键盘输入按字节发送到远端，不进行命令级解析。
- 窗口或终端容器变化时向远端发送 PTY resize。
- 远端正常退出时记录退出状态并关闭输入通道。

### 4.8 单标签终端

- 创建一个与 SSH 会话一一对应的标签。
- 标签显示连接名称和连接状态。
- 正确显示 ANSI/VT、256 色和基础真彩色输出。
- 正确传递 `Ctrl+C`、`Ctrl+Z`、`Ctrl+D`、方向键、Tab 和 Esc。
- 支持 UTF-8 输入输出、中文输入和窗口缩放。
- 关闭仍在连接的标签时提示会话将断开。
- 关闭后取消读写任务并释放 SSH session。

### 4.9 错误映射

- 覆盖 DNS 解析失败、TCP 超时和连接被拒绝。
- 覆盖握手失败、无共同算法和协议错误。
- 覆盖主机密钥未知、变化和用户取消。
- 覆盖密码错误、私钥无效、私钥口令错误和权限不足。
- 覆盖远端主动关闭、网络中断和用户取消。
- 用户提示保持简洁，技术详情包含底层错误链但不得包含敏感数据。

## 5. 测试与验证

- 使用正确及错误密码测试认证流程和三次失败限制。
- 测试无口令/带口令 RSA、ECDSA、Ed25519 私钥。
- 测试首次主机密钥确认、再次匹配、密钥变化和删除后重连。
- 测试 DNS 失败、端口拒绝、超时和连接中取消。
- 在终端运行 `vim`、`top`、`less`，验证控制键和 resize。
- 验证中文输入、彩色输出和连续日志输出。
- 重复连接和关闭，确认无残留 socket、会话和异步任务。
- 扫描日志，确认不存在密码、私钥内容和私钥口令。

## 6. 阶段交付物

- 单连接表单和测试连接功能。
- Rust SSH 连接、认证、主机密钥和 PTY 服务。
- 单标签真实终端。
- SSH 核心错误码和本地化文案。
- 真实服务器端到端测试记录。

## 7. 退出条件

- 密码和私钥认证均可稳定进入远程 Shell。
- 首次主机密钥确认与指纹变化阻断均有效。
- 常见全屏终端程序可基本使用。
- 所有连接结束路径都能释放资源。
- 无阻断级或严重级缺陷。

## 8. 本阶段不包含

- 保存连接、分组、搜索和快速连接历史。
- 系统凭据库及“记住密码”。
- 多标签会话和完整复制粘贴体验。
- SFTP 文件管理。
- 自动无感重连。
