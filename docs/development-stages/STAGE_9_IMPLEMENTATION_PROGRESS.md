# 阶段 9 实施进度：SFTP 完整工作流

## 完成状态（0.1.0-14）

阶段 9 已完成。SFTP 已从单文件面板升级为支持批量、目录、安全递归、权限管理和可靠任务历史的日常文件工作流。

## 已交付能力

- Ctrl/Command 多选、Shift 范围选择、当前页全选和批量操作。
- 多文件及目录递归上传、批量文件/目录下载，保留空目录、隐藏文件、Unicode 名称、零字节文件和基础文件修改时间。
- `ask`、`overwrite`、`skip`、`rename` 四种冲突策略；失败任务可按当前策略重试。
- 本地和远端同目录临时文件、备份恢复与原子替换；取消或失败清理任务自有临时文件。
- 默认不跟随符号链接；远端链接显示目标，递归扫描具备 64 层、100000 项和 10000 待处理项上限。
- 递归删除采用文件优先、目录后序，不跟随链接，并保护 `/`、顶级入口和常见 Home 根入口。
- 展示 Unix 数值权限、rwx、UID/GID；支持单项、批量和显式递归 chmod，完全使用 SFTP `setstat`。
- 大目录每页渐进加载 1000 项；单目录硬上限 100000 项。
- 全局 3 个传输任务并发槽、单任务保守串行文件流、取消和有界会话退出清理。
- TransferRegistry 保存最近 100 条非敏感任务元数据；重启时未完成任务转为可重试失败，不承诺跨重启断点续传。
- Windows/Tauri 原生文件拖入与浏览器拖放回退，拖入目标有持续高亮且不绕过冲突策略。
- 传输中心展示排队、扫描、运行、失败、取消、完成、文件/目录/字节进度、速度、耗时、当前路径和有限错误摘要。

## 阶段结论

路径安全、原子恢复、并发限制、大目录扫描和任务恢复均已有自动化验证。服务器不支持原子 rename 或 setstat 时会返回稳定错误，不使用 Shell 或 sudo 降级。
