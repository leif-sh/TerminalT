# 阶段 3：多会话与完整终端体验

## 1. 阶段目标

在稳定 SSH 连接和连接资产基础上，补齐多标签会话、终端交互、显示设置、保活和手动重连，使 FastTerm 达到日常 SSH 客户端的核心可用水平。

## 2. 前置条件

- 阶段 2 的连接配置、凭据读取和主机密钥记录已稳定。
- 单会话生命周期、输出背压和资源释放已通过真实服务器验证。
- 终端组件已验证选择、搜索、Unicode、鼠标事件和动态配置能力。

## 3. 对应需求

- `FR-SSH-005`。
- `FR-TERM-001` 至 `FR-TERM-005`。
- `FR-SET-001` 中与终端会话相关的设置项。

## 4. 详细开发功能

### 4.1 多会话管理

- 每个标签对应独立 SSH 会话、异步任务和终端缓冲。
- 同一连接允许打开多个独立会话。
- 支持从连接列表、快速连接和新建标签入口打开会话。
- 标签展示连接名称和连接中、已连接、已断开或失败状态。
- 标签切换时保留各自终端内容、滚动位置和搜索状态。
- 单会话失败不得修改或关闭其他标签状态。
- 关闭应用时有界等待全部会话释放，超时后安全终止剩余任务。

### 4.2 标签交互

- 支持新建、切换和关闭标签。
- 关闭活动连接时提示“会话将断开”。
- 设置中可以关闭该确认，但连接中任务仍必须正确取消。
- 支持 `Ctrl+W` 关闭当前标签。
- 支持 `Ctrl+Tab` 切换到下一个标签。
- 支持 `Ctrl+1～9` 定位前九个标签。
- 快捷键与终端远端输入发生冲突时，以产品定义的应用级快捷键为准。
- 基础版不支持标签跨窗口拖拽和分屏。

### 4.3 终端渲染与字符处理

- 支持 ANSI/VT 转义序列、256 色和基础真彩色。
- 支持中文、Emoji、宽字符、组合字符和 UTF-8 输入输出。
- 后端继续按字节流传递数据，前端终端组件负责增量解码。
- 高频输出采用批量推送和有界缓存，避免无限堆积。
- 单会话持续接收 5 MB 日志输出时保持基本交互能力。
- 支持鼠标滚轮、滚动缓冲和全屏程序的鼠标事件。
- 面板或窗口尺寸变化时节流发送 PTY resize，避免事件风暴。
- 输入法组合期间不重复、不截断且不提前发送未完成字符。

### 4.4 键盘输入

- 正确传递 `Ctrl+C`、`Ctrl+Z`、`Ctrl+D`、方向键、Tab 和 Esc。
- 正确传递功能键及终端组件支持的常用组合键。
- 保证终端获得输入焦点时，普通按键不会被应用外壳误拦截。
- 对应用级快捷键建立集中映射，避免组件分别注册导致冲突。
- 搜索框、对话框或设置表单打开时，按键只作用于当前焦点上下文。

### 4.5 选择、复制与粘贴

- 鼠标拖拽选择终端文本。
- 支持复制、粘贴、全选和清屏。
- 有文本选中时 `Ctrl+C` 执行复制；没有选中时向远端发送中断字符。
- `Ctrl+Shift+C` 始终复制。
- `Ctrl+Shift+V` 执行粘贴。
- 右键菜单提供复制、粘贴、全选和清屏。
- 粘贴内容包含多行或超过 1,000 个字符时显示预览确认。
- 预览明确说明内容可能立即在远端执行，并支持取消。
- 粘贴内容作为纯文本处理，不经过 HTML 渲染。

### 4.6 屏内搜索

- `Ctrl+F` 打开当前标签的搜索栏。
- 支持上一个、下一个和大小写敏感开关。
- 搜索范围限定为当前终端滚动缓冲。
- 展示当前匹配位置和匹配总数；无匹配时给出明确状态。
- 关闭搜索后将焦点恢复到终端输入区。
- 切换标签时搜索仅影响对应终端实例。

### 4.7 终端显示设置

- 支持从可用等宽字体中选择字体族。
- 字号范围 10～32 px，默认 14 px。
- 行高范围 1.0～2.0，默认 1.2。
- 提供浅色、深色两套内置终端主题。
- 光标形状支持块、竖线和下划线。
- 支持光标闪烁开关。
- 滚动缓冲范围 1,000～100,000 行，默认 10,000 行。
- 设置保存后立即应用到已打开终端；组件限制无法即时更新的项目明确标记为新会话生效。
- 设置变化后重新计算终端行列并同步远端 PTY。

### 4.8 Keepalive 与断线

- 默认每 30 秒发送 SSH keepalive。
- 支持关闭 keepalive，并为阶段 5 的间隔设置提供底层接口。
- 区分远端正常退出、服务器关闭、网络中断、超时和本地取消。
- 断开后保留终端缓冲内容，禁止继续向失效通道写入。
- 标签显示可读断线原因，并提供重新连接和关闭标签。
- 不实现自动无感重连。

### 4.9 手动重新连接

- 使用同一连接配置建立全新 SSH session、PTY 和 Shell。
- 已保存凭据可继续通过凭据引用读取。
- 仅本次输入的密码或口令不得无提示复用；重连前重新询问。
- 重新连接成功后在原标签中替换会话并清晰分隔新旧输出。
- 重连失败时继续保留旧缓冲，允许再次重试或关闭标签。
- 重连期间禁止并发触发多个重复连接任务。

## 5. 测试与验证

- 同时打开、切换和关闭至少 10 个空闲 SSH 会话。
- 验证一个会话认证失败、断线或关闭不会影响其他会话。
- 使用 `vim`、`top`、`less`、`tmux` 验证键盘、鼠标和 resize。
- 验证中文输入法、Emoji、宽字符、组合字符和彩色输出。
- 覆盖复制、中断信号、强制复制、粘贴确认和右键菜单。
- 覆盖搜索跳转、大小写敏感、无结果和焦点恢复。
- 验证所有显示设置的范围、持久化和运行期应用。
- 模拟网络中断和远端退出，验证状态、缓冲保留和重连。
- 验证临时凭据重连时必须重新输入。

## 6. 阶段交付物

- 多标签会话管理器。
- 完整终端输入、选择、复制粘贴和搜索体验。
- 终端显示设置。
- Keepalive、断线状态和手动重连。
- 多会话与全屏终端程序测试记录。

## 7. 退出条件

- 多会话并存、切换、关闭和异常隔离稳定。
- 常用终端全屏程序和中文输入可日常使用。
- 断线后内容保留，用户可以安全地手动重连。
- 多行和超长粘贴确认机制有效。
- 阶段范围内无阻断级或严重级缺陷。

## 8. 本阶段不包含

- 分屏、广播输入、会话录制与回放。
- 自动无感重连和远端 Shell 状态恢复。
- 命令补全、快速命令和历史增强。
- SFTP 文件操作。
