# 阶段 9：SFTP 完整工作流

## 1. 阶段目标

将现有单文件 SFTP 面板升级为可处理目录部署、批量下载、权限调整和可靠传输队列的日常文件工具。阶段结束时，大目录、网络中断、取消和权限错误不会破坏源文件或留下不可识别的半成品。

## 2. 前置条件

- 阶段 7 认证能力稳定，SFTP 可复用所有受支持认证方式。
- 当前 SFTP 浏览、单文件传输、取消和重试回归通过。
- 完成远端属性、符号链接、rename、setstat 和目录遍历能力验证。
- 确定本地临时文件、远端临时文件和原子替换策略。
- 明确递归删除的产品确认流程和路径安全规则。

## 3. 范围与非范围

本阶段包含：

- 多选、全选、批量上传下载和删除；
- 目录递归上传、下载和删除；
- 文件和目录拖拽传输；
- Unix 权限查看和修改；
- 持久化传输队列元数据、并发限制、取消和失败重试；
- 同一运行期内的可恢复传输与临时文件清理；
- 大目录的渐进式加载和进度汇总。

本阶段不包含：

- 跨应用重启的任意服务器断点续传承诺；
- 远程文本编辑，放到阶段 12；
- 压缩包自动解压、同步盘和双向目录同步；
- sudo 提权文件操作；
- 软链接创建和所有者/用户组变更。

## 4. 数据模型

### 4.1 传输任务

```ts
interface TransferJob {
  id: string
  sessionId: string
  direction: 'upload' | 'download'
  sources: string[]
  targetDirectory: string
  conflictPolicy: 'ask' | 'overwrite' | 'skip' | 'rename'
  state: 'queued' | 'scanning' | 'running' | 'paused' | 'cancelled' | 'failed' | 'completed'
  totals: { files: number; directories: number; bytes?: number }
  progress: { files: number; directories: number; bytes: number }
}
```

- 任务状态和非敏感路径可持久化用于诊断，但不得包含凭据。
- session 失效后任务进入可重试失败，不自动连接并继续写入。
- 文件级子任务由 Rust TransferRegistry 管理，不把整个目录树复制到 React 状态。

### 4.2 远端条目

补充：

- 符号链接标识和可选目标；
- 数值权限和 `rwx` 展示值；
- UID/GID（仅展示，不在本阶段修改）；
- 稳定排序字段和加载游标；
- 文件类型未知时不按普通文件处理。

## 5. 后端架构

### 5.1 TransferRegistry

- 全局并发任务上限默认 3，单任务文件并发上限保守配置。
- 使用队列调度扫描、创建目录和文件流传输。
- 每个任务拥有取消令牌、进度聚合器和有限错误列表。
- 取消优先停止新任务，再中止进行中的 I/O，并清理应用创建的临时文件。
- 终端高频输出优先级不应被大文件传输饿死。

### 5.2 递归遍历

- 默认不跟随目录符号链接。
- 维护已访问远端文件标识或规范化路径集合，防止循环。
- 设置最大深度、最大条目数和最大待处理队列。
- 所有子路径必须保持在用户选择的根路径内。
- 路径越界、类型变化和目录在扫描中消失时安全失败。

### 5.3 原子写入

- 下载写入同目录应用临时名，成功 flush/close 后原子替换目标。
- 上传使用远端临时名，完成后 rename 到最终名称。
- 不覆盖时使用无冲突名称或跳过策略。
- 取消和失败只清理本任务创建的临时文件。
- 无法原子替换的服务器明确降级并保留可诊断信息。

## 6. 详细开发功能

### 6.1 多选与批量操作

- Ctrl 点击、Shift 范围选择和当前目录全选。
- 选择状态在刷新后按路径重建，已消失条目移除。
- 批量操作显示文件数、目录数和目标路径。
- 部分失败以成功/失败/跳过汇总展示，不隐藏单项错误。

### 6.2 目录上传与下载

- 本地选择器支持多个文件和目录。
- 上传前扫描本地树，下载前扫描远端树并展示估算。
- 保留空目录、隐藏文件、Unicode 名称和基础修改时间。
- 路径长度或服务器限制导致失败时指出具体相对路径。
- 冲突策略可对单项询问，也可应用到本任务剩余项目。

### 6.3 递归删除

- 删除普通文件和空目录沿用现有流程。
- 非空目录必须显示根路径、已扫描数量和不可恢复说明。
- 删除顺序为文件优先、目录后序。
- 默认不跟随软链接，删除链接本身而非目标。
- 根目录、Home 根入口和异常短路径增加额外保护。

### 6.4 拖拽传输

- 从资源管理器拖入当前远端目录创建上传任务。
- 从远端列表拖出仅在平台能力稳定时启用；否则提供明确的“下载到”操作。
- 拖拽进入前展示目标目录高亮，禁止拖入未知或无权限目录。
- 拖拽不绕过覆盖确认和队列并发限制。

### 6.5 权限管理

- 展示数值权限和 owner/group/other 的 rwx 复选框。
- 使用 SFTP setstat 修改权限，不拼接远端 Shell 命令。
- 支持单项和批量同值修改。
- 递归 chmod 作为独立危险选项，复用安全遍历规则。
- 修改后刷新条目；部分失败展示逐项结果。

### 6.6 传输中心

- 展示排队、扫描、传输、取消、失败和完成状态。
- 展示文件数、字节、速度、耗时和当前相对路径。
- 支持取消、清除已完成、失败重试和打开本地目标。
- 暂停只有在底层可保证一致恢复时启用；否则不提供伪暂停按钮。
- 应用退出时取消活动任务并有界等待临时文件清理。

### 6.7 错误码

至少覆盖：

```text
SFTP-RECURSIVE-LIMIT
SFTP-PATH-ESCAPE
SFTP-SYMLINK-CYCLE
SFTP-PERMISSION-CHANGE-FAILED
TRANSFER-SCAN-FAILED
TRANSFER-CONFLICT
TRANSFER-TEMP-CLEANUP-FAILED
TRANSFER-ATOMIC-REPLACE-FAILED
```

## 7. 安全要求

- 本地和远端路径始终作为不可信输入。
- 不通过 Shell 命令实现 chmod、删除或目录扫描。
- 覆盖、递归删除和批量权限修改必须明确确认。
- 日志只记录脱敏根路径、计数、错误码和耗时，不记录文件内容。
- 下载目标必须经过用户选择或受控默认目录解析。
- 临时文件名包含任务随机 ID，但不包含秘密。
- 不自动跟随符号链接，不允许递归越过根路径。

## 8. 测试与验证

- 1,000 文件、100 目录、10 层深度的往返传输与校验和比较。
- 空目录、隐藏文件、Unicode、长名称和零字节文件。
- 软链接环、指向根外的软链接和扫描中目录变化。
- 目标已存在的 ask/overwrite/skip/rename 策略。
- 网络中断、权限不足、磁盘不足、取消和应用退出。
- 下载失败不破坏既有目标，上传失败不覆盖既有远端文件。
- 三任务并发下终端输入和输出仍可交互。
- 递归删除只影响确认根路径内条目。
- 批量 chmod 的成功、部分失败和刷新。

## 9. 任务拆分

1. SFTP 能力验证与路径安全设计。
2. TransferJob 模型、迁移和进度事件。
3. TransferRegistry、并发队列和取消。
4. 安全递归扫描与原子写入。
5. 多选、批量上传下载和冲突策略。
6. 递归删除和权限管理。
7. 拖拽与传输中心。
8. 大目录、故障注入、压力和安全验收。

## 10. 阶段交付物

- 传输队列与递归遍历架构说明。
- 批量/目录传输、删除、拖拽和权限管理。
- 大目录、故障恢复和路径安全测试记录。
- 更新后的 SFTP 用户说明、错误码和已知限制。

## 11. 退出条件

- 文件和目录批量上传下载结果一致且可取消。
- 递归删除、软链接和路径逃逸保护通过安全测试。
- 失败或取消不会破坏既有目标文件。
- 并发传输不会阻塞终端或超过配置上限。
- 权限查看和修改在受支持服务器上稳定工作。
- 应用退出后无活动传输、文件句柄或可清理临时文件残留。
