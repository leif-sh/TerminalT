# SFTP 文件工作流使用说明

## 批量选择

- 单击选择一个对象；按住 Ctrl/Command 可增减选择；按住 Shift 可选择连续范围。
- “全选当前页”只选择已加载页面；大目录可继续点击“加载更多”。
- 双击目录进入目录，符号链接不会被当作目录跟随。

## 上传与下载

- “上传文件”支持多选，“上传目录”会递归扫描所选目录。
- 将 Windows 资源管理器中的文件或目录拖入打开的 SFTP 面板也会创建上传任务。
- 选择多个远端对象后使用“下载到”选择本地目标目录。
- 冲突策略对整个新任务生效：询问、覆盖、跳过或自动重命名。

## 删除与权限

- 删除目录内容必须勾选“递归处理目录内容”，确认框会显示对象和目录数量。
- 根目录、顶级入口及常见 Home 根入口受额外保护。
- 权限面板按 owner/group/other 显示 rwx 复选框；递归权限修改必须单独勾选。
- 权限修改使用 SFTP，不需要也不会尝试 sudo。

## 传输中心

- 状态包括排队、扫描、传输、完成、失败和取消。
- 可查看文件/目录进度、字节、速度、耗时、当前路径和最多 20 条失败摘要。
- 失败或取消任务可在选择新的冲突策略后重试。
- 应用重启不会继续旧文件流；未完成任务会显示为失败并等待显式重试。
