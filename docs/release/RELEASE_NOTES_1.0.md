# TerminalT 基础版发布说明

## 0.1.0-11 · 阶段 7 认证兼容性

- 新增 Keyboard-Interactive 单轮/多轮认证提示，可用于动态口令和 2FA；
- 新增 Windows OpenSSH Agent 公钥发现、首选指纹与代理签名认证；
- 连接资产升级至 schema 2，旧 schema 0、1 自动迁移且不持久化临时回答；
- 连接测试、新连接、保存连接和重连共用可取消、可超时的认证状态机。

## 系统要求

- Windows 10 1809 或更新版本，64 位；
- WebView2 Runtime（安装程序可联网获取）；
- 支持 SSH-2 和 SFTP 的远端服务器。

## 功能

- 密码及 RSA、ECDSA、Ed25519 私钥认证；
- 首次主机指纹确认与指纹变化阻断；
- 多标签终端、搜索、安全粘贴、显示设置和手动重连；
- SFTP 浏览、上传、下载、覆盖保护、取消、重试和基础文件管理；
- Windows 凭据库、连接配置导入导出、诊断日志及脱敏导出。

## 安全和隐私

TerminalT 默认在本机处理并保存数据，不提供云同步或遥测。密码和私钥口令仅在用户选择保存时写入 Windows 凭据管理器；终端输入输出不会写入诊断日志。连接配置导出不包含凭据、私钥内容或口令。

## 已知限制

- 不支持 SSH Agent、跳板机、端口转发、RDP、Telnet、Serial 或 Mosh；
- 不支持分屏、会话录制、远程编辑、递归目录删除和断点续传；
- 私钥导出仅保留本机路径，迁移到其他设备后需要重新选择文件；
- 手动重连会建立全新 Shell，不恢复远端进程状态；
- 旧式、不安全的 SSH 算法不会被静默启用。

## 升级与卸载

NSIS 安装程序按当前用户安装并支持覆盖升级。应用数据和 Windows 凭据独立于程序目录，卸载应用不会自动清除连接配置、日志或系统凭据；可在卸载前从设置页清除历史、指纹和日志。
