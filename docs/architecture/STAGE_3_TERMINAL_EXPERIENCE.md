# 阶段 3：多会话与终端体验架构说明

## 当前增量

本增量在不改变阶段 2 连接资产模型的前提下，解除前端单会话限制，并复用既有 `SessionRegistry` 为每个标签维护独立的 SSH channel、命令队列和终端实例。

已实现：

- 同时新建、切换和关闭多个独立会话，单个会话状态事件只更新对应标签；
- `Ctrl+W`、`Ctrl+Tab` 和 `Ctrl+1～9` 集中式标签快捷键；
- 连接中标签关闭确认，以及可持久化的关闭确认开关；
- 当前标签独立的屏内搜索、大小写敏感、结果计数和焦点恢复；
- 选择复制、`Ctrl+Shift+C`、`Ctrl+Shift+V`、右键菜单，以及多行或超过 1,000 字符的粘贴预览；
- 字体、字号、行高、主题、光标与滚动缓冲设置，修改后即时更新全部终端并同步 PTY 尺寸；
- 100 ms PTY resize 节流、16 ms / 64 KiB 输出批处理和 30 秒 SSH keepalive；
- 断开后保留终端实例与缓冲，并显示对应会话的断线原因。
- 断线后在原标签内建立全新 SSH session、PTY 和 Shell；新旧输出之间显示分隔线。
- 已保存凭据允许复用；仅本次密码和快速连接凭据不会进入重连状态，重连对话框要求重新输入。
- keepalive 支持启停和 5～300 秒间隔，新会话及手动重连时应用。
- 应用退出会通知全部会话关闭，并有界等待最多 2 秒，避免退出无限阻塞。

## 边界与隔离

- 后端仍按字节数组跨 IPC 传输，UTF-8 增量解码由 xterm.js 负责。
- 每个 `TerminalView` 在标签切换时仅隐藏而不卸载，因此滚动缓冲、选择和搜索状态不会被其他标签覆盖。
- 终端输入只在会话状态为 `connected` 时发送，断线标签只读。
- 临时密码和私钥口令不进入会话状态、终端设置或本地存储。
- 输出事件在 Rust 端小批量合并，单批达到 64 KiB 时立即发送，避免逐块高频跨 IPC。
