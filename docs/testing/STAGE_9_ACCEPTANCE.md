## 完整门禁

提交前必须通过：

```powershell
npm run release:version
npm run release:test
npm run release:audit
```

其中包含前端 lint/测试/生产构建、Rust fmt、Clippy warnings-as-errors 以及全量 Rust 测试。Windows 凭据库测试在非交互 CI 会话中按既有约定忽略。

## 已知边界

- 不提供跨应用重启的分块断点续传；重启后从完整对象重新执行。
- 不创建软链接，不修改 owner/group，不调用 sudo。
- 远端拖出到资源管理器未启用；使用“下载到”选择本地目录。
- 原子 rename 或 setstat 不受服务器支持时明确失败，不以非原子覆盖或 Shell 命令静默降级。
