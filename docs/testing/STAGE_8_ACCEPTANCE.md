# 阶段 8 验收：网络路径与 SSH 隧道

## 验收范围

本记录覆盖阶段 8 的代理协议、多跳 SSH、连接复用、`-L/-R/-D`、压力与安全边界。测试使用进程内 SSH 服务端及真实 TCP loopback socket，不以 mock 数据替代网络转发路径。

## 自动化验收矩阵

| 能力 | 验证场景 | 结果 |
| --- | --- | --- |
| HTTP CONNECT | 无认证、Basic 认证、拒绝认证、畸形/超大响应 | 通过 |
| SOCKS5 客户端 | 无认证、用户名密码、域名/IPv4/IPv6、错误响应 | 通过 |
| Jump Host | 两个跳板加目标服务器的逐跳 `direct-tcpip` 连接 | 通过 |
| 逐跳主机密钥 | 第二跳指纹变化在目标连接前阻断 | 通过 |
| 连接池 | 两个租约复用同一传输，最后租约释放后关闭 | 通过 |
| 本地转发 `-L` | TCP echo 双向载荷 | 通过 |
| 远程转发 `-R` | 远端监听、`forwarded-tcpip`、撤销后端口关闭 | 通过 |
| 动态转发 `-D` | SOCKS5 CONNECT 后 TCP echo 双向载荷 | 通过 |
| 并发压力 | 单 SSH 传输同时承载 100 个本地转发连接 | 通过 |
| 重复生命周期 | 同一 SSH 传输连续建立、传输并关闭 100 次 | 通过 |
| 大流量持续交互 | 5 MiB 输出后继续进行终端交互 | 通过 |
| 会话隔离 | 10 个会话并行，额外认证失败不影响既有会话 | 通过 |
| 风险控制 | 非 loopback 与所有远程转发要求显式确认 | 通过 |

## 关键安全断言

- 代理密码和认证秘密不会进入连接 JSON、导出文件、日志或连接池复用键。
- Jump Host 引用在保存时检查失效引用、重复、自引用和间接循环。
- 每个跳板必须已有可信 known-host 记录；未知或变化的指纹不会被自动接受。
- 动态转发只处理 SOCKS5 TCP CONNECT；UDP 与其他命令返回不支持。
- 远程转发与非 loopback 监听在持久化层和界面层均执行风险确认。
- 关闭终端不会提前关闭隧道持有的底层 SSH 连接。
