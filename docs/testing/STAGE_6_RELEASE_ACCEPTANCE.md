## 发布门禁

以下项目无法由仓库自动化或当前单机环境替代，正式公开发布前必须在目标环境记录证据：

- Ubuntu LTS、Debian、Rocky Linux/OpenSSH Server 实机兼容矩阵；
- 8 小时长连接的内存、句柄、CPU 趋势；
- 干净 Windows 虚拟机的 NSIS 安装、覆盖升级、卸载和重装；
- 受信代码签名证书签名及签名验证；

未提供证书时生成的安装包是未签名候选包，不得对外标记为正式签名版本。

当前开发机已验证 NSIS 产物生成。MSI 不属于本阶段交付产物；当前开发机的 Windows Installer 服务不可用，WiX ICE 校验无法执行，因此发布流程固定使用 NSIS，避免依赖不可复现的系统状态。
