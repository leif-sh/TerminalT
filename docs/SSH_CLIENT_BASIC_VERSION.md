# TerminalT 基础版 SSH 客户端功能开发文档

> 文档版本：v1.0
> 产品阶段：MVP / 基础版
> 目标平台：Windows（首发）
> 技术基线：Tauri 2 + React 19 + TypeScript + Rust
> 参照产品：本机安装的 XTerminal 及其官方产品文档

## 1. 文档目的

本文用于明确 TerminalT 基础版 SSH 客户端的产品范围、功能要求、交互流程、数据结构、技术边界和验收标准，供产品、设计、前端、Rust 客户端及测试人员共同使用。

基础版只解决一个核心问题：用户能够安全地保存服务器连接，并在本地桌面应用中稳定地完成 SSH 登录、命令行操作和少量文件传输。

## 2. 产品定位

TerminalT 是一款本地优先的桌面 SSH 客户端。基础版面向需要日常登录 Linux/Unix 服务器的开发者和运维人员，不要求注册账号，所有连接信息和偏好默认保存在本机。

基础版的核心价值：

- 集中保存和快速查找 SSH 连接；
- 支持密码和私钥两种常用认证方式；
- 提供可靠、符合终端习惯的交互式 Shell；
- 提供与当前 SSH 会话共用连接的基础 SFTP 文件操作；
- 正确处理主机密钥、敏感凭据和异常断线。

## 3. XTerminal 参照与范围取舍

XTerminal 将 SSH 终端、SFTP、端口转发、连接管理、本地终端、监控、快速命令、笔记、AI 等功能整合在一个应用中。TerminalT 基础版只吸收其中完成日常 SSH 登录所必需的部分。

| XTerminal 能力 | 基础版取舍 | 说明 |
| --- | --- | --- |
| SSH 连接管理、分组、搜索 | 纳入 | 基础连接入口 |
| 密码、私钥认证 | 纳入 | 最常用认证方式 |
| 主机指纹校验 | 纳入 | SSH 安全底线 |
| 交互式 SSH 终端 | 纳入 | 产品核心 |
| 多标签会话 | 纳入 | 满足同时管理多台服务器 |
| 终端主题、字体、复制粘贴、搜索 | 纳入基础项 | 保证基本可用性 |
| 图形化 SFTP | 纳入精简版 | 只做浏览、上传、下载、新建、重命名、删除 |
| 键盘交互认证、SSH Agent | 暂不纳入 | 后续认证增强 |
| 分屏、会话录制与回放、命令补全 | 不纳入 | 非基础能力 |
| 端口转发、SOCKS5、多跳/跳板机 | 不纳入 | 网络高级能力 |

| 本地终端、快速命令、笔记、监控 | 不纳入 | 不属于基础 SSH 登录闭环 |
| AI、RDP、Telnet | 不纳入 | 与基础 SSH 客户端无关 |

## 4. 用户与使用场景

### 4.1 目标用户

- 开发者：登录开发机、测试机，查看日志并执行部署命令；
- 运维人员：维护多台 Linux 服务器，偶尔上传配置或下载日志；
- 个人用户：管理云服务器、NAS、树莓派等设备。

### 4.2 核心使用场景

1. 用户首次启动应用，新建一个服务器连接并保存。
2. 用户双击已保存连接，通过密码或私钥登录服务器。
3. 用户在终端中执行命令、复制输出、查找文本，并在多个会话间切换。
4. 用户打开当前会话的文件面板，上传配置文件或下载日志。
5. 网络中断或认证失败时，用户能看懂原因并重试。

## 5. 信息架构与主界面

基础版采用三层结构：

```text
应用窗口
├─ 左侧导航
│  ├─ 连接
│  └─ 设置
├─ 连接侧栏
│  ├─ 搜索框
│  ├─ 分组树
│  └─ 连接列表
└─ 工作区
   ├─ 会话标签栏
   ├─ SSH 终端
   └─ 可展开的 SFTP 文件面板
```

窗口首次打开时展示连接页；已有连接时显示连接列表，没有连接时显示“新建连接”引导。终端会话以标签页承载，标签标题默认显示连接名称，并使用状态图标表示连接中、已连接、已断开或连接失败。

## 6. 功能需求

### 6.1 连接管理

#### FR-CONN-001 新建和编辑连接

连接表单至少包含：

| 字段 | 必填 | 默认值 | 规则 |
| --- | --- | --- | --- |
| 连接名称 | 是 | 自动使用主机名 | 1～64 个字符 |
| 主机地址 | 是 | 无 | IPv4、IPv6 或域名，去除首尾空格 |
| 端口 | 是 | 22 | 1～65535 |
| 用户名 | 是 | 无 | 1～128 个字符 |
| 认证方式 | 是 | 密码 | 密码或私钥 |
| 密码 | 条件必填 | 无 | 可选择仅本次使用或安全保存 |
| 私钥路径 | 条件必填 | 无 | 支持选择本地私钥文件 |
| 私钥口令 | 否 | 无 | 可选择仅本次使用或安全保存 |
| 分组 | 否 | 默认分组 | 从已有分组选择 |
| 备注 | 否 | 无 | 最多 500 个字符 |
| 字符编码 | 是 | UTF-8 | 基础版固定为 UTF-8，界面可不展示 |

表单应提供“测试连接”和“保存”操作。测试成功只代表 TCP、SSH 握手和认证成功，不自动进入终端；测试结果要显示耗时或明确的失败原因。

验收标准：

- 必填字段或端口格式不正确时不能提交，并在对应字段旁提示；
- 编辑后保存立即更新列表，不影响已经建立的会话；
- 密码和私钥口令不得以明文写入普通配置文件或日志；
- 私钥文件不存在或无法读取时，在连接前明确提示。

#### FR-CONN-002 连接列表

- 按分组显示连接名称、主机地址和在线会话状态；
- 单击选中，双击连接；
- 右键或更多菜单提供：连接、编辑、复制、删除；
- 搜索支持连接名称、主机地址、用户名和备注，输入后即时过滤；
- 最近成功连接的项目可按最后连接时间排序。

删除连接前必须二次确认。删除连接配置不关闭已建立的会话，也不删除用户选择的私钥文件。

#### FR-CONN-003 分组管理

- 新建、重命名、删除分组；
- 连接可在编辑表单中切换分组；
- 删除非空分组时，将其中连接移入“默认分组”，不得级联删除连接；
- 基础版只支持单层分组。

#### FR-CONN-004 快速连接

提供不保存配置的快速连接入口，接受 `user@host` 或 `user@host:port`。用户补充认证信息后直接打开会话，关闭后不保留密码和连接记录；只在最近历史中显示脱敏后的目标地址时，必须允许用户清除历史。

### 6.2 SSH 连接与认证

#### FR-SSH-001 连接建立

建立连接时依次执行：

1. 解析主机名并建立 TCP 连接；
2. 完成 SSH 协议握手和算法协商；
3. 校验服务器主机密钥；
4. 执行用户认证；
5. 请求 PTY，默认终端类型为 `xterm-256color`；
6. 打开交互式 Shell；
7. 将本地终端尺寸同步给远端。

连接超时默认 15 秒，并允许在设置中选择 5～60 秒。连接过程中展示可取消的加载状态，取消后必须释放 socket、SSH session 和相关任务。

#### FR-SSH-002 密码认证

- 支持本次输入密码；
- 用户主动勾选“记住密码”时，使用操作系统安全凭据存储；
- 认证失败后允许重新输入，连续失败 3 次后停止自动重试；
- 界面和日志不得回显密码。

#### FR-SSH-003 私钥认证

- 支持 OpenSSH 常见 RSA、ECDSA、Ed25519 私钥；
- 支持无口令及带口令私钥；
- 文件选择器默认定位常用 `.ssh` 目录，但不扫描或上传用户密钥；
- 口令错误、密钥格式不支持、文件权限不足时分别给出错误信息；
- 私钥内容只在认证阶段读取到内存，不复制到应用数据库。

#### FR-SSH-004 主机密钥校验

首次连接未知主机时，显示：主机与端口、密钥类型、SHA-256 指纹，并提供“信任并继续”和“取消”。用户信任后将记录写入本地 `known_hosts` 等价存储。

已记录主机的指纹发生变化时，必须以高风险警告阻止默认连接；展示新旧指纹，只允许用户明确删除旧记录或确认替换，不提供自动忽略选项。

#### FR-SSH-005 会话保活与断线

- 默认每 30 秒发送一次 SSH keepalive，可关闭；
- 远端正常退出时显示退出状态；
- 网络断开、服务器关闭、超时等情况显示可读原因；
- 已断开标签保留当前屏幕内容，并提供“重新连接”和“关闭标签”；
- 重新连接使用同一连接配置，但不得无提示地重复使用仅本次输入的密码。

基础版不做自动无感重连，因为远端前台进程和 Shell 状态无法可靠恢复。

### 6.3 终端

#### FR-TERM-001 终端渲染与输入

- 支持 ANSI/VT 转义序列、256 色和基础真彩色；
- 支持中文、Emoji、宽字符、组合字符和 UTF-8 输入输出；
- 支持鼠标滚轮、滚动缓冲和终端程序的鼠标事件；
- 窗口或面板尺寸改变时发送 PTY resize；
- 正确传递 `Ctrl+C`、`Ctrl+Z`、`Ctrl+D`、方向键、Tab、Esc 等按键；
- 输入法组合期间不得重复或截断字符。

#### FR-TERM-002 标签页

- 每个标签对应一个独立 SSH 会话；
- 支持新建、切换、关闭标签；
- 标签显示连接名和状态；
- 关闭仍在连接的标签时提示“会话将断开”，可在设置中关闭该提示；
- 支持 `Ctrl+W` 关闭当前标签、`Ctrl+Tab` 切换下一个标签、`Ctrl+1～9` 定位标签。

基础版不支持分屏和标签跨窗口拖拽。

#### FR-TERM-003 复制、粘贴和选择

- 鼠标拖拽选择文本，支持全选与复制；
- 有文本选中时 `Ctrl+C` 执行复制，无选中时向远端发送中断字符；
- `Ctrl+Shift+C` 始终复制，`Ctrl+Shift+V` 粘贴；
- 粘贴多行或超过 1,000 个字符时弹出预览确认，降低误执行风险；
- 支持右键菜单：复制、粘贴、全选、清屏。

#### FR-TERM-004 屏内搜索

- `Ctrl+F` 打开搜索；
- 支持上一个、下一个、大小写敏感开关；
- 搜索范围为当前终端滚动缓冲；
- 关闭搜索后焦点回到终端输入区。

#### FR-TERM-005 显示设置

基础版支持以下全局设置：

- 字体族：从等宽字体中选择；
- 字号：10～32 px，默认 14 px；
- 行高：1.0～2.0，默认 1.2；
- 浅色、深色两套内置终端主题；
- 光标形状：块、竖线、下划线；
- 光标闪烁开关；
- 滚动缓冲行数：1,000～100,000，默认 10,000。

设置保存后立即应用到已打开终端；若终端组件限制无法即时更新，应明确标记需新会话生效。

### 6.4 基础 SFTP 文件管理

SFTP 面板依附于当前 SSH 标签，共用主机、端口、认证和主机信任信息。基础版不提供双栏文件管理器和远程在线编辑。

#### FR-SFTP-001 浏览目录

- 打开面板后默认进入远端用户 Home 目录；
- 显示文件名、类型、大小、修改时间和 Unix 权限；
- 支持进入目录、返回上级、输入路径跳转、刷新；
- 目录加载中显示状态，权限不足或路径不存在时保留当前可用路径并提示错误；
- 文件列表默认目录优先、按名称排序。

#### FR-SFTP-002 文件操作

- 上传本地文件到当前远端目录；
- 下载远端文件到用户选择的本地目录；
- 新建文件夹；
- 文件或目录重命名；
- 删除文件和空目录；
- 覆盖同名文件前确认；
- 删除前确认，并明确远端删除通常不可恢复。

基础版不支持非空目录递归删除、批量传输、断点续传、拖拽传输、权限修改、软链接创建和远程编辑。

#### FR-SFTP-003 传输状态

- 每个上传或下载任务显示文件名、方向、已传输大小、总大小、进度、速度和状态；
- 支持取消进行中的任务；
- 成功、失败、取消状态可区分；
- 失败项展示可读原因并允许重试；
- 同时最多执行 3 个任务，其余排队。

### 6.5 应用设置与本地数据

#### FR-SET-001 通用设置

- 启动时恢复上次窗口大小和位置；
- 语言基础版只提供简体中文，但字符串必须使用国际化资源管理；
- 可设置连接超时、keepalive 间隔、关闭会话确认和默认下载目录；
- 提供清除最近连接历史和清除已保存主机指纹的入口。

#### FR-SET-002 数据导出与导入

基础版支持连接配置的本地 JSON 导出和导入，用于手动备份。导出文件默认不包含密码、私钥口令和私钥内容；导入遇到同 ID 的连接时生成新 ID，并提示重名。

#### FR-SET-003 日志

- 记录应用启动、连接阶段、错误代码和 SFTP 任务结果；
- 不记录终端输入输出正文；
- 不记录密码、私钥内容、私钥口令或完整认证报文；
- 日志中的用户名、主机地址允许保留用于诊断，但应在设置页明确告知；
- 默认保留最近 7 天并限制总大小。

### 6.6 错误反馈

所有连接错误必须映射为用户可理解的信息，同时保留可复制的技术详情。至少覆盖：

| 错误类型 | 用户提示示例 |
| --- | --- |
| DNS 解析失败 | 无法解析主机名，请检查地址或网络设置 |
| TCP 超时 | 连接超时，请检查主机、端口和防火墙 |
| 连接被拒绝 | 目标主机拒绝连接，请确认 SSH 服务和端口 |
| 主机密钥变化 | 服务器身份与历史记录不一致，连接已阻止 |
| 密码错误 | 认证失败，请重新输入密码 |
| 私钥无效 | 无法读取或解析所选私钥 |
| 私钥口令错误 | 私钥口令不正确 |
| 权限不足 | 当前账号无权执行此文件操作 |
| 远端主动关闭 | 服务器已关闭当前会话 |
| 网络中断 | 网络连接已中断，可尝试重新连接 |

## 7. 关键业务流程

### 7.1 首次连接

```text
新建连接 → 填写地址和认证信息 → 测试或直接连接
→ SSH 握手 → 首次主机指纹确认 → 用户认证
→ 创建 PTY 与 Shell → 打开终端标签
```

任一步失败都停留在可修正的位置，不保存“仅本次使用”的敏感信息。

### 7.2 已保存连接

```text
搜索/选择连接 → 双击 → 读取连接配置与安全凭据
→ 校验已知主机指纹 → 认证 → 打开终端
```

### 7.3 断线重连

```text
连接中断 → 标签进入已断开状态 → 保留缓冲内容
→ 用户点击重新连接 → 必要时重新输入凭据
→ 建立全新 Shell → 原标签替换为新会话
```

## 8. 数据模型建议

### 8.1 ConnectionProfile

```ts
interface ConnectionProfile {
  id: string
  name: string
  host: string
  port: number
  username: string
  authType: 'password' | 'privateKey'
  credentialRef?: string       // 操作系统凭据库引用，不是密码
  privateKeyPath?: string      // 只保存路径
  privateKeyPassphraseRef?: string
  groupId: string
  note?: string
  lastConnectedAt?: string
  createdAt: string
  updatedAt: string
}
```

### 8.2 HostKeyRecord

```ts
interface HostKeyRecord {
  host: string
  port: number
  algorithm: string
  fingerprintSha256: string
  publicKey: string
  trustedAt: string
}
```

### 8.3 SessionState

会话状态只存在于进程内，不持久化：

```ts
type SessionStatus =
  | 'connecting'
  | 'host-key-check'
  | 'authenticating'
  | 'connected'
  | 'disconnected'
  | 'failed'

interface SessionState {
  id: string
  connectionId?: string
  title: string
  status: SessionStatus
  startedAt: string
  lastError?: string
}
```

## 9. 技术实现边界

结合当前工程的 Tauri、React、TypeScript 和 Rust 技术栈，建议职责划分如下：

| 层 | 职责 |
| --- | --- |
| React 前端 | 连接列表、表单、标签、终端视图、SFTP 面板、设置和错误提示 |
| 终端渲染组件 | VT 渲染、输入、选择、搜索、滚动缓冲、resize |
| Tauri Command/Event | 前后端请求响应、会话事件、二进制流与生命周期管理 |
| Rust SSH 服务 | socket、握手、认证、PTY、Shell、keepalive、host key 校验 |
| Rust SFTP 服务 | 目录读取、元数据、上传、下载、重命名、删除、任务进度 |
| 本地数据库 | 连接、分组、主机密钥和设置；不存储明文秘密 |
| 系统凭据库 | 密码和私钥口令 |

实现要求：

- 每个 SSH 会话由独立异步任务管理，UI 关闭标签时显式取消；
- 终端数据采用字节流传递，在 Rust 侧不要假设每个数据块都是完整 UTF-8 字符串；
- 高频终端输出应批量推送并做背压，避免逐字符跨 IPC；
- 会话、SFTP channel 和传输任务使用不可猜测 ID，不向前端暴露裸指针或文件句柄；
- Rust 层统一生成稳定错误码，前端负责本地化文案；
- 文件选择与下载路径必须使用 Tauri 最小权限能力配置。

基础版只承诺 SSH-2，不支持 SSH-1。算法选择优先使用维护中的 SSH 库安全默认值，不为兼容旧服务器默认开启已知弱算法。

## 10. 安全要求

1. 密码和私钥口令只能在用户授权时写入操作系统凭据库。
2. 数据库、配置文件、日志、崩溃报告均不得包含明文秘密。
3. 首次主机密钥必须由用户确认；指纹变化必须阻断连接。
4. UI 中密码默认遮挡，并提供按住或短时显示能力。
5. 连接测试结束后立即释放仅本次使用的凭据引用。
6. 私钥不得被应用复制、修改、同步或包含在配置导出中。
7. 粘贴多行命令必须确认，提示其可能立即在远端执行。
8. 远端路径和文件名视为不可信输入，展示时转义，不得注入 HTML 或本地命令。
9. 应用升级或崩溃后不得自动恢复并执行尚未发送的终端输入。
10. 发布包应关闭开发者工具默认入口，并限制 Tauri 命令白名单。

## 11. 非功能要求

### 11.1 性能

- 冷启动到出现主窗口：主流 Windows 设备上不超过 3 秒；
- 点击已保存连接到出现终端：除网络与认证耗时外，应用额外开销不超过 500 ms；
- 单会话持续接收 5 MB 日志输出时界面可交互、无崩溃；
- 同时保持 10 个空闲 SSH 会话时，标签切换无明显卡顿；
- SFTP 列出 5,000 个文件时不阻塞整个应用窗口。

### 11.2 稳定性

- 单个会话失败不得导致其他会话断开或应用退出；
- 关闭应用时有界等待并释放所有 SSH/SFTP 任务；
- 数据写入使用事务或原子替换，异常退出不能损坏全部连接数据；
- 终端长时间运行 8 小时无明显内存持续增长。

### 11.3 可用性与无障碍

- 所有主要操作可通过键盘完成；
- 状态不能只用颜色表达，需配合图标或文字；
- 危险操作使用明确对象名称和后果描述；
- 错误对话框提供复制技术详情入口。

### 12.2 发布验收条件

- 本文所有纳入项完成，无阻断级或严重级缺陷；
- 密码和私钥认证均通过端到端测试；
- 主机密钥首次确认和变化阻断均有效；
- 终端可稳定运行常见全屏程序；
- SFTP 基础操作可用且传输失败不会破坏原文件；
- 应用退出后无残留 SSH 连接或后台传输；
- 配置导出和日志中未发现密码、私钥口令或私钥内容；
- Windows 安装包完成签名、安装、升级和卸载验证。

## 14. 明确不在基础版范围内

以下能力不应在基础版开发过程中顺带实现，以控制范围：

- SSH Agent、FIDO/U2F、证书认证、键盘交互认证；
- 代理、跳板机、多跳连接；
- 本地、远程、动态端口转发；
- 会话分屏、广播输入、并发命令、会话录制与回放；
- 命令补全、历史增强、快速命令和动态变量；
- SFTP 批量队列、递归目录、断点续传、远程编辑和权限管理；
- 本地终端、服务器监控、笔记、AI；
- RDP、Telnet、Serial、Mosh 等其他协议；
- 账号登录、云同步、团队共享和跨设备同步；
- 插件系统和第三方扩展市场。
