# TerminalT 前端设计规范

## 1. 视觉目标

TerminalT 使用面向开发者与运维人员的深色桌面终端视觉语言：克制、精密、高信息密度，同时保持连接状态和危险操作清晰可辨。视觉基准为 [`../docs/terminalt-prototype-v2-clasht-style.png`](../docs/terminalt-prototype-v2-clasht-style.png)。规范与参考图冲突时，以参考图为准。

禁止套用通用浅色后台、白色大卡片、超大标题、营销落地页、拟物玻璃球或高饱和渐变模板。

## 2. 布局

- 桌面端采用固定主导航、上下文侧栏和弹性工作区的三层结构。
- 主导航保持窄而稳定；列表与设置侧栏宽度固定；终端工作区优先获得剩余空间。
- 窗口最小尺寸为 800×600；窄窗口优先压缩侧栏，不遮挡主操作和终端。
- 对话框居中，最大高度不超过视口；内容滚动，标题和操作区保持可见。
- 高密度数据使用紧凑列表、表格或小型状态卡，不使用大片留白。

## 3. 色彩

- 应用底色使用接近黑色的蓝灰：`#02060d`、`#050d18`、`#081525`。
- 表面层使用低透明蓝黑，不使用纯黑大面积覆盖。
- 主强调色使用电蓝 `#3478e5`～`#5f8cff`；允许少量紫色作为层次，不作为主要操作色。
- 成功使用青绿色 `#32d7a8`；警告使用琥珀色；危险使用柔和红色 `#fb7185`。
- 边框细而冷，通常为低透明蓝灰；活动态可增加蓝色描边和微弱外发光。
- 文本层级必须清晰：主文本接近白色，次文本蓝灰，辅助文本更暗但仍满足可读性。

## 4. 形状与层次

- 常用圆角为 7～12px；主对话框可使用 14～16px。
- 卡片和面板依赖边框、轻微渐变和有限阴影区分层级。
- 发光只用于品牌、活动连接、焦点和关键状态，不让所有组件同时发光。
- 按钮保持紧凑；主按钮使用实色蓝，次按钮使用半透明深色表面。
- 图标使用线性、统一描边风格；优先复用 `public/icons.svg` 和 `Icon` 组件。

## 5. 字体与密度

- 界面使用系统无衬线字体；终端、路径、指纹和错误码使用等宽字体。
- 页面标题通常 20～26px；卡片标题 11～15px；正文 10～13px。
- 英文眉题允许大写和较宽字距，但不得替代中文功能标题。
- 控件高度通常 34～44px；列表项 42～52px；保持桌面工具的紧凑效率。

## 6. 交互状态

- hover、focus、active、disabled、loading、error 必须都有可辨状态。
- 键盘焦点不能只依赖颜色变化，应使用边框或外轮廓。
- 状态不能只用颜色表达，同时配合文字、图标或形状。
- 长任务显示当前阶段、取消入口和脱敏错误；避免无说明的无限 spinner。
- 危险操作明确展示对象和后果，确认按钮使用危险色，默认焦点不落在危险按钮。

## 7. 认证界面专项规则

- 认证方式选择器延续连接对话框的分段按钮，不新增独立页面。
- keyboard-interactive 对话框必须固定显示连接名称和目标，防止凭据输错会话。
- 远端 instruction 和 prompt 作为不可信文本，保持换行但不渲染 HTML。
- `echo=false` 使用密码框；`echo=true` 使用普通文本框，不根据提示内容猜测类型。
- 多轮认证显示“等待服务器/需要输入/正在验证”的明确阶段，不展示验证码历史。
- SSH Agent 状态使用小型状态块，区分可用、无密钥、不可用和签名失败。

## 8. 可访问性

- 所有输入有可见标签；图标按钮有 `aria-label`。
- 对话框具备正确 role、标题关联、焦点循环和关闭后焦点恢复。
- 文本与背景保持足够对比度；辅助文字不得低到无法阅读。
- 支持仅键盘完成连接、认证、取消和错误详情复制。
- 不使用持续剧烈动画；加载和状态动画应轻量且支持系统减少动态效果。

## 9. 实现约束

- 优先复用现有 CSS 变量、组件、圆角、边框和按钮样式。
- 新样式放在对应功能附近，避免创建第二套设计系统。
- 不为一次性布局引入大型 UI 框架。
- 数据变化频繁的区域避免昂贵模糊、滤镜和大面积阴影。
- 在 100%、125%、150% Windows 缩放下检查文本、对话框和焦点状态。

## 10. 完成自检

- [ ] 与参考图的深色蓝黑、电蓝/紫色点缀和紧凑密度一致。
- [ ] 没有引入通用白色后台或营销页面风格。
- [ ] 主操作、次操作、危险操作层级明确。
- [ ] hover、focus、disabled、loading、success、error 状态完整。
- [ ] 800×600 和常用 Windows 缩放下可使用。
- [ ] 所有状态不只依赖颜色表达。
- [ ] 对话框焦点、键盘操作和关闭恢复正确。
- [ ] 远端文本已转义，秘密不会显示在历史、错误或持久化状态中。
- [ ] 复用了现有组件与设计 token，没有无必要的新依赖。
